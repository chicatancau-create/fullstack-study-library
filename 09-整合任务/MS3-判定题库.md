# MS3 · G0–G9 判定题库

> 目标：把 G0–G9 十个关口全部建设为"可盲测、有隐藏测试、有评分指南"的判定题包。
> 工作量：中。优先级：P1。
> 前置：MS1、MS2 完成（判定题依赖项目与实验资产）。

## 全局规则

1. 在仓库根新建 `08-判定题库/` 目录。
2. 每个关口目录结构：
   ```
   08-判定题库/GX-关口名/
   ├── README.md              # 关口说明、评分 rubric
   ├── 学生包/
   │   ├── 题面.md            # 任务说明
   │   ├── 起始代码/          # 学生拿到的脚手架
   │   └── 公开测试/          # 学生可跑的测试
   ├── 教师包/
   │   ├── 隐藏测试/          # 学生看不到的判定测试
   │   ├── 答案密钥/          # 参考答案
   │   ├── 评分指南.md        # rubric + 常见错误
   │   └── 故障变体/          # 多套试卷的差异化
   └── 评估者指南.md          # 外部评估者怎么用
   ```
3. **学生包与教师包物理隔离**，学生克隆时只能拿到学生包。
4. **隐藏测试**必须能自动判定通过/失败，不依赖主观判断。
5. 提交格式：`feat(G0): MS3-G0 判定题包`。

## G0 环境与工程习惯

- 学生包：一个含冲突的 Git 仓库 + 一个含 bug 的小项目
- 隐藏测试：干净克隆、冲突解决、最小复现、AI 工单
- 评分：能否不看教程完成 Git 闭环、能否定位 bug 根因

## G1 计算机与 Web 基础

- 学生包：静态网站骨架 + C 数据结构起始代码
- 隐藏测试：响应式、WCAG 2.2、HTTP 状态码、内存错误（E01 隐藏变体）
- 评分：可访问性 ≥90 分、C 内存安全无错误

## G2 JavaScript/TypeScript

- 学生包：陌生 TS CLI 题面 + 异步任务池起始代码（基于 E02 但简化）
- 隐藏测试：CLI 全参数、异步边界、类型边界、运行时校验
- 评分：所有隐藏测试通过 + 类型覆盖率 ≥80%

## G3 React 前端工程

- 学生包：一个含竞态/缓存 bug 的 React 应用
- 隐藏测试：E03/E05 变体、非教程变更、可访问性
- 评分：bug 全部修复 + 新增功能通过测试

## G4 Node.js 后端 + 数据库

- 学生包：项目 02 起始代码（基于 MS1 P02 简化）
