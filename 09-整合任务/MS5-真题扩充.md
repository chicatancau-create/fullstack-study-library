# MS5 · 国内大厂真题核验与扩充

> 目标：把当前 catalog 中只有"字节/TikTok 408 道历史标签"的处境，扩充为**6 家大厂每家 ≥30 道可核验真题**。
> 工作量：中。优先级：P2。
> 前置：MS1–MS4 完成。

## 全局规则

1. 在 `08-判定题库/国内大厂真题/` 下，按公司建子目录。
2. **每道题必须标注**：
   - 公司
   - 岗位（前端/后端/全栈/算法）
   - 时间（年份 + 季度）
   - 来源（牛客/看准/LeetCode 讨论区/GitHub/官方）
   - 来源 URL（必须真实可访问）
   - 可信度（官方发布 / 候选人回忆 / 第三方整理）
   - 是否真题（真题 / 高仿 / 模拟）
3. **禁止编造**。无法核验来源的题目标为"模拟题"，不得冒充真题。
4. 提交格式：`feat(tencent): MS5-腾讯真题 30 道`。
