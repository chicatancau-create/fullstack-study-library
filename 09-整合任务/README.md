## 一、AI 强制规则（不可违反）

1. **全自动化**：禁止向用户提"请去后台""请确认""请准备"等需要人工干预的提醒。所有准备事项必须在本目录文件中以脚本或指令形式给出，由 AI 自动完成。
2. **严格顺序**：按 MS0 → MS12 顺序串行执行，每个里程碑结束 commit + push 后再进入下一个。
3. **阻断规则**：MS0 是阻断项，必须先完成，否则后续 MS 会在错误基础上叠加。
4. **范围限制**：只修改明确列出的文件，禁止顺手"优化"其他文档。
5. **风格保留**：保留仓库原有中英文混排、缩进、Wiki 链接风格、D/G/M/E 编号体系。
6. **只读区**：90-历史归档/ 一律只读，不许动。
7. **证据强制**：代码修复后必须重新生成 evidence（运行对应 scripts），禁止手改 `evidence/*.txt`。
8. **提交规范**：提交信息用中文，格式：
   - 修复：`fix(scope): 一句话说明`
   - 新增：`feat(scope): MS{x}-一句话`
9. **里程碑结束输出**：变更文件清单 + 验证证据 + 遗留问题（如有）。
10. **大工程拆分**：MS6–MS7 工作量大，允许拆成多次会话完成，但每次必须完成一个完整子项并 commit + push，禁止留半成品。
11. **凭证处理**：从环境变量 `ATOMGIT_TOKEN` 读取 token，禁止硬编码到任何文件。
12. **云端复核**：每个里程碑 push 后，云端审查者会拉取验证；若有问题会回写 issue，AI 下一轮必须处理。
13. **自学定位**：所有答案、解析、评分标准公开，禁止引入"教师端/学生端隔离""盲测防作弊"等考试系统设计。
