# 专项：算法与数据结构深度训练

> 排期口径：本页原第 1–52 周属于 C 压缩主题索引；深度路线实际日期与关口以 [[../03-执行计划/深度路线与工时预算|D01–D96 / G0–G9]] 为准。核心实验可复用项目证据，算法与实验工时已计入总预算。

**定位：贯穿 G1–G9 的基础能力｜优先级：P0｜默认每周 4 小时；冲刺增加投入时从其他活动调配并重估日历。**

> 算法训练的目标是限时、正确、可解释地解决陌生问题，不是刷题数量或背模板。题量是过程指标，独立重做、变体迁移和复杂度分析才是验收依据。

## 一、训练语言与深度标准

- 主力语言只选一门完成大部分题目：TypeScript、Python、Java、Go、C++ 或 C# 均可。
- C++ 适合训练内存与标准库细节，Python 适合快速验证思路；语言选择不改变算法验收标准。
- 同一道核心题至少用主力语言独立实现一次；求职前再用第二语言实现 10 道代表题，防止只会背 API。
- 不把“看过题解”计为完成。关闭题解后能重写、讲清不变量并处理边界，才计入有效题量。

| 级别 | 判定标准 | 证据 |
| --- | --- | --- |
| L1 理解 | 能复述思路并完成例题 | 代码、测试、复杂度分析 |
| L2 独立 | 不看答案在限时内完成同类新题 | 首次提交记录、计时和边界用例 |
| L3 迁移 | 能处理变体、比较两种以上方案 | 变体题、方案对比和反例 |
| L4 工程应用 | 能把结构用于真实模块并测量 | 项目代码、基准测试和故障分析 |

## 二、题单顺序与数量

以下题单是可选训练来源，允许去重、按短板选题；不要求把重叠题单全刷完，也不把题量作为毕业硬门槛。按专题推进，不一开始混刷公司标签：

1. **LeetCode 热题 100**：建立通用题型框架。
2. **面试经典 150**：补充数组、字符串、图、DP 和面试变体。
3. **SQL 50 基础与进阶**：连接、聚合、窗口、Top-N 和业务查询。
4. **专项题单**：图论、DP、并查集、Trie、单调栈/队列、系统设计题。
5. **目标公司高频题**：基础题单完成后使用，不能代替通用能力。

| 目标 | 有效题量建议 | 适用口径 |
| --- | --- | --- |
| 全栈/AI 应用 | 250–350 道，包含 Hot 100、SQL 和至少 30 道变体 | 能独立解决多数 Medium，具备基础 Hard 分析能力 |
| 后端/基础设施 | 350–500 道，重点 Medium，Hard 30–50 道 | 能限时编码并讨论大规模约束与工程实现 |
| 算法/竞赛强化 | 500 道以上并参加周赛 | 不以题量替代数学、建模和比赛表现 |

表中数量是训练规划参考，目标岗位不同可调整；陌生题正确性、复杂度、边界、变体与稳定表现才是硬门槛。数量只统计能够独立重做的题。重复提交、复制题解和只看不写不累计。

## 三、专题覆盖与代表题

| 专题 | 必须掌握 | 代表题或工程迁移 |
| --- | --- | --- |
| 数组与哈希 | 前缀和、差分、计数、区间、去重 | 两数之和、最长连续序列、和为 K 的子数组；幂等键与缓存索引 |
| 双指针 | 相向/同向、快慢、原地修改 | 三数之和、盛水、移动零；流式去重与区间扫描 |
| 滑动窗口 | 窗口合法性、收缩时机、单调队列 | 无重复字符最长子串、滑动窗口最大值；限流与实时统计 |
| 链表 | 哨兵、反转、环、合并、K 组操作 | 反转链表、环形链表 II、合并 K 个链表 |
| 栈与队列 | 单调栈、最小栈、表达式、双端队列 | 每日温度、接雨水、最小栈；任务调度与语法解析 |
| 二叉树/BST | 递归/迭代遍历、层序、LCA、序列化、树形 DP | 二叉树最大路径和；依赖树与权限继承 |
| 图与搜索 | DFS/BFS、拓扑、最短路、连通性 | 课程表、岛屿数量；依赖解析和任务编排 |
| 并查集 | 路径压缩、按秩合并、连通分量 | 账户/资源合并、关系连通 |
| 回溯 | 排列、组合、子集、剪枝和恢复现场 | 全排列、组合总和；规则组合搜索 |
| 二分 | 有序查找、旋转数组、答案二分 | 搜索旋转排序数组、最小可行容量 |
| 堆与贪心 | Top-K、数据流中位数、区间调度 | 第 K 大元素、数据流中位数；优先任务与热点统计 |
| 动态规划 | 状态、转移、拓扑序、空间优化 | 背包、LCS、编辑距离、股票、网格路径 |
| 单调结构 | 单调栈/队列、下一个更大元素 | 柱状图最大矩形、滑动窗口最大值 |
| Trie/字符串 | 前缀树、KMP 基础、匹配与边界 | 实现 Trie、搜索联想、敏感词与路由匹配 |
| 位运算与数学 | 位掩码、异或、 gcd、模运算、溢出 | 只出现一次的数字、权限位和布隆过滤器认知 |
| SQL | Join、分组、窗口、去重、Top-N | 留存、连续登录、每笔订单最新状态 |
| 并发设计 | 同步、可见性、生产者消费者、交替执行 | 有界队列、线程池、限流器；必须附竞态与阻塞测试 |

## 四、每周训练协议

默认每周总计 4 小时，已经包含在深度路线预算中：

1. **专题新题 90 分钟**：可分两次，每次 45 分钟；先独立再复盘，不强制每次题数。
2. **错题重做 45 分钟**：按 1、3、7、21 天检索练习，不看旧代码。
3. **限时训练 60 分钟**：一至两道当前水平的陌生题，练读题、编码、调试和解释。
4. **SQL / 工程连接 45 分钟**：业务查询或数据结构迁移，按当周项目调配。
5. **每两周综合套题**：G4 后可把第 1、3 项共 150 分钟改为 90–120 分钟套题与复盘，替换原活动，不额外叠加。Hard 只按岗位与短板选择。

每题记录：

- 题号、专题、难度、语言和日期；
- 首次是否独立、耗时、提交结果；
- 核心不变量和正确性理由；
- 时间/空间复杂度及数据规模约束；
- 空输入、单元素、重复、极值、溢出等边界；
- 至少一种替代方案及其代价；
- 变体、错误原因和下次重做日期；
- 与真实工程的连接，无连接时明确写“仅算法训练”。

## 五、按能力关口的里程碑

旧第 5/10/15/24/32/36/52 周题量表不再作为必达进度；零基础必须先学语言与基本结构，再逐步计时。对已记住的题只计复习，不作为陌生题能力证据。

| 关口 | 专题重点 | 必须验收 |
| --- | --- | --- |
| G1 | 数组、哈希、栈队列、二分与复杂度 | 能写基本结构/算法，边界有测试；不设早期几十题硬指标 |
| G2 | 双指针、窗口、链表、树与基础递归 | 换输入/约束仍能独立实现，解释不变量与复杂度 |
| G3 | 堆、回溯、图搜索与基础 DP | 两类陌生变体，能比较方案与处理极值 |
| G4 | 图/拓扑/并查集、SQL 关联与窗口 | 一条工程迁移或业务查询有测试与代价说明 |
| G5–G7 | 综合专题、主修语言、限时套题 | 连续两次模拟符合评分，Hard 根据岗位选择而非强制题量 |
| G9 | 不同题目的综合实操 | 按综合考核中的算法/SQL 任务与硬门槛验收 |

参考题量可用于估算练习时间；若熟题多但陌生变体仍失败，减少新题，优先重做与解释。求职前可用第二语言做少量代表题，不强制第三语言。

## 六、限时模拟评分

每次模拟按 100 分记录：

| 项目 | 分值 | 通过要求 |
| --- | ---: | --- |
| 正确性与边界 | 35 | 核心用例通过，无已知静默错误 |
| 思路与不变量 | 20 | 能说明为什么算法成立 |
| 复杂度与数据规模 | 15 | 时间/空间分析正确，能判断何时超时或超内存 |
| 编码质量 | 15 | 命名、结构、资源释放和错误处理清楚 |
| 沟通与变体 | 15 | 能边写边讲，并处理至少一个条件变化 |

连续两次达到 80 分才算该阶段稳定；不能只记录 accepted 截图。

## 七、常见误区

- 用刷题总数掩盖重复题、复制题解和无法独立重做。
- 只背模板，不变换数据规模、输入约束或目标条件。
- 为追 Hard 忽略数组、链表、边界和编码正确率。
- 同时用多语言刷同一批简单题，制造“多语言都会”的假象。
- 把 LeetCode 与工程割裂；真正后端深度还包括并发、I/O、存储、故障和测量。
