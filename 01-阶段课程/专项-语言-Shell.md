## 1. 执行模型

- Shell 是进程与命令编排语言，不是编辑器或终端本身；解释器、当前目录、环境变量和子进程决定行为。
- Bash 主要传文本流，PowerShell 管道传 .NET 对象；语法和错误模型不能混写。
- 外部命令、内建命令、函数、别名和可执行文件的解析顺序影响结果。
- Windows 还需区分 cmd、PowerShell、WSL、Git Bash 的路径、编码、权限和换行。

## 2. 输入、引用与展开

- Bash 参数、单/双引号、转义、数组、glob、命令替换和 `$@` 的边界；不默认可随意 unquote。
- IFS、分词、路径空格、通配符和空输入；优先数组和显式循环。
- PowerShell 参数绑定、对象属性、管道和 `$_`；经其他 Shell 调用时注意变量被提前展开。
- 环境变量、本地变量、导出变量和子进程继承；秘密不进入命令历史和日志。
- 文本编码、UTF-8 BOM、CRLF/LF 和本地化输出属于外部数据边界。

## 3. 进程、流与状态

- stdin/stdout/stderr、重定向、管道、here-doc 和临时文件。
- 退出码、条件执行 `&&/||`、trap、子 Shell 与后台任务。
- `set -euo pipefail` 的收益与例外；命令位于条件、管道或替换中时不按直觉退出。
- 读取命令输出而不吞退出码，避免 `cmd | tail` 掩盖失败。
- 进程启动、终止、超时、等待和僵尸/孤儿进程；自动化必须可观测。

## 4. 文件与数据操作

- 路径拼接、绝对/相对路径、符号链接/ junction、递归和文件名换行。
- 创建、复制、移动、删除的原子性、幂等和覆盖风险；重要操作先校验源/目标。
- 文本逐行处理，结构化 JSON/XML/CSV 使用对应解析器而非正则拼接。
- 临时目录、权限、清理 trap 和并发锁；多实例不能相互删除文件。
- 下载校验来源、TLS、哈希和解压路径，禁止 zip slip。

## 5. 错误、安全与可恢复性

- 任何写操作先说明输入、目标、权限、失败时状态和回滚。
- 删除、强制覆盖、提权、远程执行、安装与系统配置变更需要明确边界，不把 `sudo` 当默认。
- 避免 `eval` 和不可信字符串拼接命令；外部参数用数组/参数化接口。
- 日志可脱敏、可定位，不输出令牌、Cookie 或完整敏感配置。
- 可恢复脚本分检查、执行、验证阶段；中断后重跑不会重复破坏。

## 6. 测试与诊断

- 用临时目录和合成文件测试空输入、空格、中文、权限、失败与重复执行。
- `bash -n`、ShellCheck、PowerShell AST/Script Analyzer 按环境使用。
- 跟踪输出仅用于调试，发布时避免泄露秘密；记录命令退出码和关键变量。
- 在干净环境验证解释器版本、依赖和平台，不把本机别名当脚本依赖。

## 7. 教学项目与验收

### 项目

编写项目备份与验证脚本：

1. 只读取明确文件清单，创建带时间戳的备份目录。
2. 逐文件复制并校验 SHA-256，输出结构化结果。
3. 处理路径空格、中文、已存在目录、复制失败和中断。
4. 失败返回非零，不删除源文件；测试重复执行。
5. Bash 与 PowerShell 可任选其一实现，另一门能读懂。

### 通过标准

- [ ] 能解释 quoting、glob、退出码和管道的一个真实坑。
- [ ] 脚本对空输入、失败、重复执行和中断有明确行为。
- [ ] 结构化数据使用解析器，秘密不会进入日志。
- [ ] 文件写操作有校验、错误传播和恢复路径。
- [ ] 在声明的平台/解释器版本下测试通过。

## 8. 常见误区

- 用未引用变量处理文件名，导致分词和 glob 误删。
- 把命令打印成功当退出成功，忽略管道真实退出码。
- 用 sed/正则修改 JSON 或未知编码配置，破坏文件结构。
- 默认提权、强制删除或覆盖，缺少源/目标确认。
- 将本机路径、别名、编码和 Shell 行为当作跨平台保证。
