## 学习清单

### Node.js 与服务端基础

- [ ] 事件循环、非阻塞 I/O、线程池和 CPU 密集型任务的影响。
- [ ] Stream、Buffer、文件上传限制、背压和资源释放的基本概念。
- [ ] 配置管理、环境变量、密钥边界、优雅退出和健康检查。
- [ ] 进程崩溃、未处理拒绝、超时和依赖服务失败的处理策略。

### API 与分层

- [ ] REST 资源建模、方法语义、状态码、分页、过滤、排序和版本策略。
- [ ] Fastify 路由、Hook、插件、序列化/校验和错误处理。
- [ ] 路由 → 服务 → 数据访问的职责边界；控制器不堆业务规则。
- [ ] DTO、领域对象、数据库记录的差异；避免把内部模型直接暴露。
- [ ] Zod 或等价运行时校验；请求体、参数、查询和环境变量均验证。
- [ ] OpenAPI 文档、统一错误结构、请求 ID 和可操作错误信息。
- [ ] 分页限制、输入长度限制、JSON 大小限制、请求超时和速率限制。

### 认证与授权

- [ ] 认证（你是谁）与授权（你能做什么）的区别。
- [ ] Session/Cookie 与 Bearer Token/JWT 的撤销、存储、CSRF 和 XSS 取舍。
- [ ] 密码哈希使用 Argon2id 或 bcrypt 等专用算法，绝不自行设计加密。
- [ ] 登录、退出、刷新、找回密码的风险；通用登录失败提示。
- [ ] 服务端逐资源鉴权、RBAC/所有权检查，禁止仅隐藏前端按钮。
- [ ] CORS 不是认证机制；CSRF、XSS、注入、暴力破解的基本防御。

### 测试与联调

- [ ] 业务规则单元测试、API 集成测试、数据库测试隔离。
- [ ] 成功、非法输入、未认证、无权限、资源不存在、冲突和依赖失败。
- [ ] Mock 的边界：不把所有内部实现都 mock 掉。
- [ ] 前后端契约联调、错误展示、请求取消和重复提交。
- [ ] 结构化日志不记录密码、Token、Cookie 或敏感个人数据。

## 最小实践

实现任务 API 最小闭环：

- 注册、登录、退出、当前用户。
- 项目与任务的 CRUD、分页、过滤和排序。
- 用户只能访问自己有权限的项目，越权返回符合安全语义的响应。
- 使用统一错误结构、请求 ID、输入校验和 OpenAPI。
- 至少覆盖一条业务单元测试和一组真实 API 集成测试。

## 阶段验收

- [ ] 能画出一次请求经过校验、认证、授权、业务、数据库和响应的路径。
- [ ] 所有变更操作均在服务端鉴权，不存在仅依赖客户端传入用户 ID 的信任。
- [ ] 非法输入不会进入业务层，未处理异常不会泄露堆栈或秘密。
- [ ] 测试覆盖正常、失败和越权路径，且可重复执行。
- [ ] API 文档与实际行为一致；服务可优雅停止并释放连接。
- [ ] 能说明当前认证方案的撤销、过期、存储和攻击面取舍。

## 常见误区

- 把 JWT 等同于安全，或把敏感数据放入可解码 payload。
- 用 200 包装所有错误，导致客户端、监控与缓存难以正确处理。
- 只验证请求格式，不验证资源归属；只测 CRUD，不测失败路径。
