# 标记与样式专项：HTML 与 CSS——文档、渲染与可访问性

**层级：P0 Web 基础｜说明：HTML 是标记语言，CSS 是样式语言，不是通用编程语言；仍需按计算与渲染模型深入学习。**

## 1. 从源码到像素

- HTML 解析为 DOM，CSS 解析为 CSSOM，经样式计算、布局、绘制、合成形成页面。
- DOM 是运行时的对象树，不等于 HTML 字符串；脚本、无效标记和 Shadow DOM 会改变结构。
- CSS 的声明经来源、层叠、继承和计算得到最终值；布局不是简单按源码顺序摆放。
- 网络、字体、图片、脚本和主线程长任务会影响呈现与交互，不能只检查静态截图。

## 2. HTML 语义与文档结构

- doctype、html/head/body、元信息、标题层级、 landmark 和文档大纲。
- 使用 button、a、input、select、dialog、table 等原生语义，不用 div 模拟一切。
- 链接用于导航，按钮用于动作；不可用元素的键盘行为必须真实验证。
- 图片替代文本、媒体字幕/描述、表格标题/表头和列表语义按内容而非视觉决定。
- 自定义数据属性和 ARIA 只补语义缺口，不覆盖原生行为。

## 3. 表单与输入边界

- label、name、type、required、min/max、pattern、autocomplete 和输入模式。
- 原生约束校验只是用户体验层，服务端仍必须校验。
- 错误提示与字段关联、焦点移动、草稿、重复提交和失败恢复。
- 文件上传的类型/大小/内容限制、下载文件名与不可信 HTML。
- autofill、密码管理器、粘贴和移动键盘属于真实用户路径。

## 4. CSS 值、盒模型与层叠

- content/padding/border/margin、content-box/border-box、替换元素和固有尺寸。
- 选择器、优先级、继承、初始值、层叠来源与层叠层；避免用 !important 解决所有冲突。
- 长度、百分比、em/rem、vw/vh、容器查询单位和计算函数。
- 格式化上下文、定位、z-index 与层叠上下文；不要只无限增大 z-index。
- display、流内/流外、浮动历史影响与现代布局选择。

## 5. 布局与响应式

- Flexbox 的主轴/交叉轴、伸缩、换行与最小内容尺寸。
- Grid 的轨道、区域、自动放置、minmax 和隐式轨道。
- 容器/媒体查询、移动优先、相对单位和响应式图片。
- 内容溢出、长单词、表格、代码块和 200% 缩放；固定高度常导致裁切。
- 视觉顺序与 DOM 顺序不一致会影响键盘和读屏，不用 order 掩盖结构问题。

## 6. 视觉、动画与性能

- 颜色、对比度、焦点可见、系统深色与 forced-colors。
- transform/opacity 适合多数动画，布局属性和大范围阴影/滤镜成本需测量。
- `prefers-reduced-motion` 和用户控制；动画不阻断阅读和操作。
- 字体加载、布局偏移、图片尺寸、懒加载和内容可见性按指标优化。
- 渲染性能用浏览器 Performance/Layers 等工具定位，不凭“GPU 加速”猜测。

## 7. 可访问性与安全

- 键盘顺序、焦点、弹窗焦点圈定/返回、读屏名称和状态通知。
- 错误不只靠颜色，触摸目标、文本缩放和减少动态效果。
- HTML 注入、属性注入、javascript: URL、target=_blank、不可信 iframe 和 CSS 外链资源。
- Markdown/富文本必须清洗，不以 CSS 隐藏代替授权或数据保护。
- 使用 axe/Lighthouse 辅助，人工验证工具无法判断的语义与操作。

## 8. 教学项目与验收

### 项目

实现无框架的多页内容网站：

- 首页、列表、详情、表单和 404，语义与 landmark 完整。
- 手机/桌面、200% 缩放、长文本和深色模式可用。
- 仅用键盘完成导航、筛选、弹窗和表单。
- 用网络面板观察资源，修复一次布局/焦点/溢出问题。

### 通过标准

- [ ] 能解释 DOM、CSSOM、布局与合成，而非只背标签。
- [ ] 能分析盒模型、层叠和层叠上下文导致的真实问题。
- [ ] 表单具备标签、错误、键盘和失败恢复。
- [ ] 自动与人工可访问性检查有证据，未覆盖项明确。
- [ ] 不用框架也能完成响应式和基本性能优化。

## 9. 常见误区

- 用 div+onclick 模拟按钮，却没有键盘、焦点和语义。
- 用绝对定位、固定高度和超大 z-index 堆页面。
- 把 Lighthouse 分数当完整可访问性证明。
- 只按设计稿像素，不测试长文本、缩放和真实内容。
- 认为 CSS 隐藏内容就完成权限或敏感数据保护。
