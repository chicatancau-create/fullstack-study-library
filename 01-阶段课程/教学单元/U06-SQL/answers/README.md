# U06 自测答案

1. **约束**：主键唯一标识一行且非空；唯一约束防重复（可复合）；外键保证引用存在（可级联）；CHECK 限制范围/枚举。它们共同保护数据库层不变量。
2. **SQLite 外键默认关闭**：历史兼容；开启后每次写入要检查父表，增加开销，删除/更新可能失败。生产连接应在每次打开时显式 `PRAGMA foreign_keys=ON`。
3. **不能**。回滚只撤销当前事务未提交的写；已提交数据不会回退，外部副作用（邮件、支付、消息）也不会自动撤销，需要补偿/对账。
4. **不一定**。复合索引 `(a,b)` 的最左前缀是 `a`；只查 `b` 通常不能用该索引。列顺序要匹配查询的等值/范围模式。
5. **代码回滚**是部署旧版本；**数据恢复**是把数据还原到某个一致状态。旧代码可能读不懂新 schema/新数据，迁移必须双向兼容或有恢复方案。

## 练习提示

- 基础 1：`record_tags(record_id, tag_id, PRIMARY KEY(record_id,tag_id))`，两个外键；查标签用 JOIN。
- 基础 2：`LEFT JOIN` + `COALESCE(SUM(...),0)` + `GROUP BY`；没有记录的用户 COUNT=0。
- 基础 3：建 `(status, minutes)` 索引后用 `EXPLAIN QUERY PLAN` 看是否使用；注意范围列放最后。
- 边界 5：`BEGIN` → 插入 → 违反唯一 → `rollback` → 查 count，前后一致。
- 边界 6：SQLite `.backup` 生成一致快照；直接复制正在写的文件可能拿到半写页，恢复后损坏。
