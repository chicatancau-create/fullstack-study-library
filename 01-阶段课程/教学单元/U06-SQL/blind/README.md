# U06 盲测：独立未见任务

> 不附答案。要求独立设计 schema、写约束/查询/事务测试，并保留原始输出。

## 任务：多租户学习记录库（SQLite 版）

1. 表：`tenants`、`users`、`records`、`tags`、`record_tags`。
2. 约束：租户名唯一；用户属于租户；记录属于用户且 `tenant_id` 必须与用户一致（用复合外键或触发器，说明取舍）；标题 1–60；分钟 >=0；状态枚举；同一用户标题唯一。
3. 查询：
   - 每个租户的记录数与总分钟（含 0 记录租户）。
   - 每个用户按状态分组的计数。
   - 带多个标签的记录（HAVING 计数）。
4. 事务：
   - 创建记录 + 关联标签必须原子；任一失败回滚。
   - 删除租户级联删除用户/记录/关联，验证无孤儿。
5. 索引：为“租户 + 状态 + 时间”查询设计复合索引，给出 `EXPLAIN QUERY PLAN` 前后对比。
6. 迁移：给 records 增加 `created_at`（先可空→回填→加 NOT NULL），写出可回滚步骤。

**交付**：schema、测试、计划输出、迁移步骤、未覆盖项（PostgreSQL/并发/真实备份）。不得只测 happy path；不得把 `PRAGMA foreign_keys` 留在关闭状态。

## 评分要点（自评）

- 约束是否真的在数据库层，能否挡住直接 SQL 写入。
- 跨租户一致性是否用约束/触发器保证，而不是只靠应用层。
- 事务失败后是否无半状态，级联删除是否无孤儿。
- 索引是否有计划证据，迁移是否可回滚。
