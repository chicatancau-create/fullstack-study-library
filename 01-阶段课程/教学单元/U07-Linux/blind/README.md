# U07 盲测：独立未见任务

> 不附答案。要求在一台**真实 Linux 或 WSL** 上完成；Git Bash 结果不能替代。

## 任务：进程、端口与日志诊断

1. 启动一个监听本地端口的进程（自写 Node/Python 均可），用 `ss -ltnp` 或 `lsof -i` 找到 PID 与命令行。
2. 用 `ps` 确认命令行/启动时间；先 SIGTERM，等待退出；若超时再 SIGKILL。记录两次退出码。
3. 制造一次“端口被占用”：启动两个同端口进程，记录第二个的报错与退出码；不要杀陌生进程。
4. 写日志脚本：统计 ERROR 行数；文件不存在时退出码非 0；无 ERROR 时返回 0 且输出 0。
5. 用 `find -print0` 处理含空格文件名；对比 `for f in $(find ...)` 的错误结果。
6. 用 `ulimit -n` 查看限制，解释达到上限时 accept/open 会发生什么；不要实际打满生产资源。
7. 用 `stat`/`ls -l` 读权限；创建 600 文件，用另一个用户/组验证不可读（需要相应权限，做不了就写明）。

**交付**：命令、退出码、`ss`/`ps` 原始输出、日志脚本、权限验证、未执行项。不得在共享/生产机器上杀陌生进程或打满资源。

## 评分要点（自评）

- 是否先确认命令行再杀进程，是否优先 SIGTERM。
- 端口冲突是否留下真实报错与退出码。
- 日志脚本是否正确处理“无匹配”和“文件不存在”。
- 是否明确区分真实 Linux 与 Git Bash。
