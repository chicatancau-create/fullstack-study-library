# U04 盲测：独立未见任务

> 不附答案。要求独立实现并用确定性测试证明竞态处理。

## 任务：可搜索的学习记录列表

实现 React 19 + TS 组件：

1. 搜索框（受控输入）与状态筛选（全部/进行中/已完成）。
2. 输入变化后 300ms 防抖再请求；组件卸载/参数变化时取消旧请求。
3. 显示 loading、empty、error、ready 四类状态；error 有重试按钮。
4. 旧请求晚到不能覆盖新结果；用 deferred 测试证明。
5. 搜索框有 label；筛选按钮有 `aria-pressed`；状态消息可被辅助技术感知。
6. `tsc --noEmit`、`vitest run`、`vite build` 全部通过。

测试要求：

- 防抖：输入 3 次只发最后一次请求（可用假定时器）。
- 竞态：先发 A 后发 B，先 resolve B 再 resolve A，A 不得覆盖 B。
- 取消：卸载/切换后旧请求不得 setState；不得出现 act 警告。
- 失败/空/重试各一条。

**交付**：源码、测试、三条命令原始输出、未覆盖项（真实 API、浏览器视觉、读屏）。不得只测 mock 调用次数而不测用户可见结果。

## 评分要点（自评）

- 竞态修复是否同时有取消与版本检查。
- 防抖是否清理定时器，是否真的只发最后一次。
- 四类状态是否可感知，测试是否按 role/text 查询。
- 是否明确写出未验证项。
