# U02 盲测：独立未见任务

> 不附答案。要求独立完成，保留命令、原始输出与截图；不得把 `examples/` 原样复制后声称独立完成。

## 任务：三页可访问站点

在干净目录中实现：

1. `index.html`、`list.html`、`form.html` 三页，共享一份 CSS。
2. 导航在三页间可互相到达，当前页有 `aria-current="page"`。
3. 列表页至少 3 条内容；表单页含文本输入、下拉、复选框与提交按钮，全部有 label。
4. 空标题提交时显示文本错误、`aria-invalid="true"`、焦点回到输入框；成功时显示 `role="status"` 消息。
5. 320px 与 1280px 下无横向溢出；根字号 200% 下无控件越界。
6. 仅用键盘完成：首页 → 列表 → 表单 → 提交成功。
7. 用 axe 或等价工具扫描三页，保存原始结果；人工检查焦点可见与跳转链接。

**交付**

- 源码与运行说明。
- 四档宽度（320/375/768/1280）的溢出处方与数值。
- 键盘轨迹（每步 `document.activeElement`）。
- axe 原始输出与未覆盖项。
- 一段说明：哪些问题自动工具没发现、你怎么人工确认。

## 评分要点（自评）

- 语义标签是否真实使用，而不是 div + role 堆砌。
- 焦点是否可见、顺序是否合理、错误是否可感知。
- 是否用测量说话，而不是只交截图。
- 是否明确写出未验证项（读屏、真实设备、跨浏览器）。
