# U09 自测答案

1. **二分不变量**：若目标存在，它一定在当前区间内。闭区间用 `low <= high`，命中后 `mid±1`；半开区间用 `low < high`，边界写法不同。混用会漏元素或死循环。
2. **lower_bound**：返回第一个 `>= target` 的位置（0..len），不是“等于目标”的任意位置；重复值下返回最左。普通二分返回某个相等下标或 -1。
3. **LRU 需要双向链表**：命中/更新要把节点 O(1) 移到头部，超容量要 O(1) 删尾；删除任意节点需要前驱，单链表做不到。哈希表只负责 key→node 定位，不维护顺序。
4. **区间合并先排序**：按起点排序后只需与 `merged[-1]` 比较；相接是否合并由业务定义，本单元 `start <= last_end` 合并。
5. **环形缓冲 count**：`head` 指向最旧，`count` 区分满/空；仅 `head == tail` 在满和空时都成立，无法区分。写满后 `head` 前移覆盖最旧。

## 练习提示

- 基础 1：返回 `low`（第一个 >= target 的位置）；空数组返回 0，尾部返回 len。
- 基础 2：双指针从两端收缩；多解时返回哪一对取决于移动规则，测试要固定预期。
- 基础 3：`peek` 只读 map/node.value，不 `_remove/_add_front`。
- 边界 5：容量 1 写 1/2/3，`to_list` 只应 `[3]`。
- 边界 6：`binary_search_with_steps` 与线性计数对比；只用于说明增长，不当作性能基准。
