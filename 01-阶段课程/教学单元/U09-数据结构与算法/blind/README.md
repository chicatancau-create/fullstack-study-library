# U09 盲测：独立未见任务

> 不附答案。要求独立实现、覆盖边界，并保留测试与比较次数证据。

## 任务：有序结构与小容量缓存

1. 实现 `search_range(items, target)`：返回第一个和最后一个等于 target 的下标；不存在返回 `(-1,-1)`。要求 O(log n)，空数组/单元素/全相同/首尾都要测。
2. 实现 `insert_interval(intervals, new)`：插入并合并，返回新列表；覆盖空、完全包含、相接、无重叠。
3. 实现 `LFUCache(capacity)`：按访问频率淘汰，频率相同按最久未用；`get/put` 平均 O(1)。写淘汰与更新测试。
4. 实现 `RingBuffer` 的 `peek_oldest/peek_newest`，容量 1 与回绕测试。
5. 对 1024 个有序元素，记录 `search_range` 的比较次数；与线性扫描对比，说明为什么不是实际耗时基准。

**交付**：源码、测试、比较次数、复杂度说明、未覆盖项（并发/内存/真实数据分布）。不得只测 happy path；不得用 `list.index` 冒充 O(log n)。

## 评分要点（自评）

- 二分边界是否覆盖重复值与首尾，是否 O(log n)。
- LFU 的频率/时序淘汰是否可解释，是否 O(1) 平均。
- 区间插入是否处理包含/相接/乱序。
- 是否区分复杂度模型与实测耗时。
