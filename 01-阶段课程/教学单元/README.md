## 单元约定

1. 示例必须真实运行，输出写入 `evidence/`；预期输出只写“形状”，精确数字以证据为准。
2. 每个单元至少一个常见错误：原文、定位步骤、修复、回归。
3. 练习分基础/边界；自测与盲测分开，答案放 `answers/`，盲测题不附答案。
4. 不把“读完/抄完”当作能力；独立未见任务必须由学习者本人完成，资料库不代填 G/M 状态。
5. 术语第一次出现时给前置解释；零基础单元不堆 Serializable、RPO/RTO 等词而不解释。
