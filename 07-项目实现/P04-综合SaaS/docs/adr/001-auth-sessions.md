# ADR 001：scrypt 密码 + 不透明会话令牌

## 状态

已采纳（2026-11-07）

## 背景

需要注册、登录、登出与会话过期。候选：JWT 无状态令牌；服务端会话表 + 不透明随机令牌；
第三方身份提供商。

## 决策

密码用 Node `crypto.scryptSync` 加 16 字节随机盐；会话令牌为 32 字节随机值，数据库只存
SHA-256，12 小时过期；登出删除会话行。

## 原因

- 无状态 JWT 难以即时撤销，需要额外黑名单；本项目规模小，会话表更直接。
- 不透明令牌不携带用户信息，泄露数据库也拿不到可用令牌（只有哈希）。
- 第三方 IdP 超出 MVP，且无法本地验证。

## 代价

- 每次请求多一次数据库查询；高并发需要连接池与索引（`token_hash` 主键）。
- 多实例部署需要共享会话存储（当前就是共享 PG，可直接扩展）。

## 回滚

若改为 JWT，保留 `sessions` 表用于刷新令牌与撤销；密码哈希格式不变。
