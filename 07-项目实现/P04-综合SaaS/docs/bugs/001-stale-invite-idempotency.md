# Bug 001：成员被移除后，旧邀请仍按“幂等成功”返回

## 现象

bob 接受邀请成为成员，随后被 owner 移除。bob 再次用同一邀请 token 调用
`POST /invitations/accept`，接口返回 `200 { idempotent: true }`，但 bob 并不是成员；
客户端会误以为已恢复访问，后续请求却得到 404。

## 影响

- 客户端状态与服务端不一致，可能反复重试并展示错误提示。
- 不涉及越权：成员关系没有被恢复；但“成功”语义错误。

## 根因

`accept` 在邀请 `status = 'accepted'` 时直接返回成功，只检查邀请状态，没有检查当前
`memberships` 是否仍存在。

## 修复

幂等分支查询 `memberships`：存在则返回实际角色与 `idempotent: true`；不存在则返回
`409 membership_removed`，要求重新邀请。见 [src/app.js](../../src/app.js)。

## 回归测试

`tests/app.test.js` 中“成员被移除后旧邀请不能再次‘幂等’接受”：接受 → 移除 → 再接受，
断言 409 且成员列表仍为 404。

## 预防

- 幂等响应必须校验当前资源状态，而不是只校验请求是否处理过。
- 状态机测试要覆盖“成功后资源被删除”的后续重放。
