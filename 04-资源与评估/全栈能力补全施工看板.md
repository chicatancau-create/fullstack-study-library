## 一、状态定义

| 状态 | 含义 | 可用证据 |
| --- | --- | --- |
| 未开始 | 没有源码、测试或原始输出 | 只有任务描述 |
| 进行中 | 已有部分产物，但门禁或证据不完整 | 代码/文档 + 未通过的检查 |
| 本机自测通过 | 在开发机干净目录中按 README 复现，门禁非零退出 | 命令、退出码、原始输出 |
| 干净环境通过 | 在独立干净克隆/隔离环境复现，依赖与运行时固定 | 环境清单、锁文件、原始输出 |
| 限定范围验收通过 | 满足统一验收标准，且明确写出未覆盖范围 | 证据 manifest + 复核记录 |
| 阻断 | 缺工具、缺真实环境、缺外部来源或需他人确认 | 阻断原因与下一次验证条件 |

规则：

1. 每批只交付一个可独立验收的增量；先让检查失败，再实现，再复跑。
2. 任一必需步骤失败必须非零退出；空测试、缺文件、关键跳过不算通过。
3. 性能、并发、恢复结论必须有环境、输入和原始样本；不能外推为生产结论。
4. 个人 G/M 状态不因本看板任何“完成”而变化。
