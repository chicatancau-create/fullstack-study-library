## 一、使用规则

1. 公开练习：先限时作答，再对照“参考要点”；错题记入错题本，48 小时后复测。
2. 私有盲测：从 `blind-set` 抽题，90 分钟闭卷；评分只写 [data/blind-score-template.csv](data/blind-score-template.csv)，
   不写“感觉会了”。
3. 评分按要点给分，不按字数；未答出关键边界按 0 分。
4. 同一题连续两次满分后，间隔 7 天再复测；否则视为短期记忆。
5. 本页题目是练习资产，不是个人能力证明；G/M 状态仍以综合考核为准。

## 二、评分口径

| 维度 | 权重 | 判据 |
| --- | --- | --- |
| 正确性 | 50% | 结果正确、边界与失败路径覆盖 |
| 过程 | 20% | 能说明假设、复杂度、取舍 |
| 可验证 | 20% | 给出测试/反例/验证命令 |
| 表达 | 10% | 结构清楚，术语使用准确 |

盲测总分 = 各题得分之和；低于 70% 视为未通过，错题必须复测。

## 四、SQL（P-SQL，15 题）

使用项目 02/04 的合成 schema：`workspaces(id, name)`、`members(workspace_id, user_id, role)`、
`tasks(id, workspace_id, title, status)`。

| ID | 题目 | 难度 | 参考要点 |
| --- | --- | --- | --- |
| P-SQL-01 | 查每个工作区任务数，含 0 | 易 | LEFT JOIN + COUNT(t.id)，不是 COUNT(*) |
| P-SQL-02 | 查没有任务的 workpace | 易 | NOT EXISTS 优先于 NOT IN（NULL 风险） |
| P-SQL-03 | 每个工作区最新一条任务 | 中 | 窗口函数 ROW_NUMBER 或相关子查询 |
| P-SQL-04 | 删除重复标题保留最小 id | 中 | 自连接/窗口 + 事务；先 SELECT 验证 |
| P-SQL-05 | 统计每个 owner 的工作区数 | 易 | JOIN + GROUP BY + HAVING |
| P-SQL-06 | 找出成员数超过 5 的工作区 | 中 | GROUP BY + HAVING；与席位限制区分 |
| P-SQL-07 | 任务状态占比 | 中 | 条件聚合 `SUM(CASE...)` 或 `FILTER` |
| P-SQL-08 | 连续 3 天有任务的工作区 | 难 | 日期减 row_number 分组（gaps and islands） |
| P-SQL-09 | 更新标题但避免唯一冲突 | 中 | 先查冲突、事务、唯一约束兜底 |
| P-SQL-10 | 分页稳定性（相同 created_at） | 中 | 复合排序 `(created_at,id)`，不用 OFFSET 大页 |
| P-SQL-11 | 索引：workspace_id + status 查询 | 中 | 复合索引顺序、选择性、EXPLAIN 验证 |
| P-SQL-12 | 事务：转账式扣减 | 中 | 行锁/条件更新、CHECK 约束、失败回滚 |
| P-SQL-13 | 隔离级别：读已提交下的写偏差 | 难 | 说明写偏差、FOR UPDATE/串行化取舍 |
| P-SQL-14 | 窗口：每工作区第二新任务 | 中 | ROW_NUMBER 过滤 rn=2 |
| P-SQL-15 | 对账：两张表差异 | 中 | FULL OUTER JOIN / EXCEPT；NULL 处理 |
