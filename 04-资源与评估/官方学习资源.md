# 官方学习资源

> 原则：以官方文档和规范为主，教程为辅。文档版本应与项目依赖一致；不要同时收藏多套重复课程。

## 使用方法

1. 先读概念和最小示例，再关闭教程独立复现。
2. 对关键行为写一个小实验或测试，不只摘抄定义。
3. API 细节查对应版本文档，概念问题回到规范和原理。
4. 搜索结果、AI 回答和博客只能作为线索，最终以可运行验证和官方资料为准。

## 工程与 Web 基础

- [MDN Web Docs](https://developer.mozilla.org/)：HTML、CSS、JavaScript、Web API、HTTP 与可访问性。
- [web.dev](https://web.dev/)：浏览器性能、响应式、可访问性和现代 Web 实践。
- [Git 官方文档](https://git-scm.com/doc)：Git 概念、命令与 Pro Git。
- [WHATWG HTML Living Standard](https://html.spec.whatwg.org/)：需要核对 HTML 标准行为时阅读。
- [OWASP Top 10:2025](https://owasp.org/Top10/2025/)：当前 Web 安全风险基线；项目逐项映射 A01–A10。
- [OWASP Cheat Sheet Series](https://cheatsheetseries.owasp.org/)：认证、会话、CSRF、XSS、上传等具体防御。

## JavaScript 与 TypeScript

- [MDN JavaScript](https://developer.mozilla.org/docs/Web/JavaScript)：语言、内置对象与异步 API。
- [JavaScript.info](https://javascript.info/)：系统教程，作为补充练习来源。
- [TypeScript Handbook](https://www.typescriptlang.org/docs/handbook/intro.html)：类型系统与工程配置。
- [Node.js 官方文档](https://nodejs.org/docs/latest/api/)：运行时 API；实际项目应切换到所用版本。
- [npm 官方文档](https://docs.npmjs.com/)：依赖、scripts、版本与工作区。

## React 与前端工程

- [React 官方文档](https://react.dev/learn)：组件、状态、Effect、渲染与架构思维。
- [Vite 官方文档](https://vite.dev/guide/)：开发、构建、环境变量和静态资源。
- [React Router](https://reactrouter.com/)：路由与数据模式，按项目采用的模式阅读。
- [Testing Library](https://testing-library.com/docs/)：以用户行为为中心的测试。
- [Playwright](https://playwright.dev/docs/intro)：浏览器自动化和端到端测试。
- [WCAG 2.2](https://www.w3.org/TR/WCAG22/)：可访问性验收参照；结合具体成功准则，不只看工具分数。
- [WAI-ARIA Authoring Practices](https://www.w3.org/WAI/ARIA/apg/)：复杂组件交互模式；优先使用原生 HTML。
- [axe-core](https://github.com/dequelabs/axe-core)：自动可访问性检查；必须配合键盘、焦点、缩放等人工验证。

## 每个阶段的阅读上限

为避免资料囤积，建议：

- 一个主题保留 1 份主教程 + 1 份官方参考。
- 每周新增收藏不超过真正读完和复现的数量。
- 读完必须产出代码、测试、图或自己的解释，否则只标记“看过”，不标记“掌握”。
- 阶段验收前优先补弱项，不因为新文章或新框架更换主线。
