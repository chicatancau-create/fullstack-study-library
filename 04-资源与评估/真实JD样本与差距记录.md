## 四、样本内频次（分母 11，仅描述本样本）

分母 11：JD-01–06、JD-08–12 这 11 份有完整任职要求；JD-07 不计入。

| 要求 | 出现份数 | 出现在 |
| --- | --- | --- |
| 至少一门编程语言 | 11/11 | 全部有要求的样本 |
| 本科及以上 / 计算机相关专业 | 8/11 | JD-01–05、08、11、12 |
| 前端框架（React 或 Vue 至少一种） | 6/11 | JD-01、02、05、06、09、12 |
| 前端工程化 / CI-CD / TDD 实践 | 6/11 | JD-01、05、06、09、10、12 |
| AI 能力为必需（含 AI Coding、RAG/Agent） | 6/11 | JD-02、03、06、08、11、12 |
| 系统设计与架构能力 | 5/11 | JD-01、02、10、11、12 |
| 性能优化与稳定性 | 5/11 | JD-01、03、05、11、12 |
| 端到端交付 / 上线验证 | 4/11 | JD-06、08、11、12 |
| Node.js 服务端（框架或全栈能力） | 3/11 | JD-05、06、12 |
| 数据库（MySQL/PostgreSQL/NoSQL） | 3/11 | JD-01、02、12 |
| 大数据栈（Spark/Flink/Hive/Kafka） | 2/11 | JD-02、04 |
| 英语可作为工作语言 | 1/11 | JD-09（Must have） |

另计“优先/加分”而非必需：AI 相关 5 处（JD-01、04、05、06、08）；云原生 2 处（JD-09、JD-10）。

结论只限三条，不外推：

1. **语言 11/11、学历 8/11** 是这份样本里最稳的门槛；框架 6/11 集中在“全栈/前端”类岗位，纯后端岗（JD-03、04、11）不要求。
2. **“全栈”在本样本里有四种写法**：JD-06 是 Node.js 全栈（Express/Koa/Nestjs），JD-11 是 Java 为主 + App/H5 + 上线验证，JD-12 是前端偏重 + 后端概念与 AI 能力，JD-01 是前端纵深 + 数据库/接口调优。只背一种组合会在另外三种上失分。
3. **AI 已进入 6/11 岗位的必需项**（另有 5 处加分），写法包括“用 AI 写高质量代码”“AI Coding 完成交付上线”“RAG/Tool Calling/Prompt Engineering 实践”；把 AI 只当扩展话题会与过半样本脱节。
