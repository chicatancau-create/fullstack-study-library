【加分】了解 AWS、Docker 或 Kubernetes。

### JD-10 Thoughtworks Senior Developer（西安，资深）

【加分】AWS、Azure、Kubernetes、Docker 实际使用经验；在外部技术社区有分享、开源或博客产出。

### JD-11 美团 全栈开发工程师（个人清单STL）-点评技术部（2 年，上海）

【必需】本科及以上，计算机及相关专业，2 年以上互联网研发经验；扎实的计算机科学功底、编程基础和数据结构算法基础，能写高质量简洁代码；精通 Java（或至少一门主流后端语言），具备复杂业务系统分析与设计经验，具备线上服务稳定性保障能力；**具备全栈交付能力，能独立完成「方案设计 → 后端开发 → App/H5 实现 → 上线验证」完整流程**；具备大模型应用研发实践经验，熟练使用各类 AI 编码/研发工具并有真实提效案例；良好沟通合作与持续学习能力。

【优先】有 UGC、内容社区业务开发经验；有个人博客、研究过优秀开源源码并有心得。

### JD-12 字节跳动 AI全栈开发工程师（抖音精选，深圳）

【必需】本科及以上，计算机、通信和电子信息科学、数学等相关专业优先；扎实前端/全栈工程能力，熟悉 JavaScript/TypeScript/HTML/CSS，熟悉 React/Vue 等至少一种主流前端框架；具备实际全栈开发经验，理解 HTTP、RESTful API、数据库、缓存、消息队列、服务治理等基础概念，熟悉 Node.js/Python/Go/Java 任一后端技术栈；有 AI Agent 或 LLM 应用实践经验，熟悉 RAG、Tool Calling、Prompt Engineering 等核心方向；具备业务抽象、系统设计、工程质量与主人翁意识。

【加分】有完整全栈项目经验，能独立完成从页面、接口、数据到部署验证的端到端交付；有 LangChain/Eino 等 AI 框架深度使用经验，或有 AI 评测体系建设经验；有 C 端 AI 业务落地场景、参与或主导过优秀开源项目、有技术博客产出。

结论只限三条，不外推：

1. **语言 12/12、学历 9/12** 是这份样本里最稳的门槛；明确要求 React/Vue 的只有 5/12，集中在全栈/前端岗——JD-03、04、09、10、11 都不要求前端框架，JD-07 写的是“前端或后端框架之一”。**“全栈”不等于“必须会 React/Vue”**，把多选一当必要条件会高估前端框架的权重。
2. **“全栈”在本样本里有四种写法**：JD-06 是唯一**强制** Node.js 服务端框架的岗位（Express/Koa/Nestjs + 前端框架 + 工作原理），JD-11 是 Java 为主 + App/H5 + 上线验证，JD-12 是前端偏重 + 后端概念 + AI 能力，JD-01 是前端纵深 + 数据库/接口调优。Node 在另外 4 份里只是“可选后端之一”，所以 Node 必须练到能讲清原理，但不要据此推断所有全栈岗都以 Node 为主。
3. **AI 已进入 7/12 岗位的必需项，另有 9 处加分**：必需侧写法是“用 AI 写高质量代码 / AI Coding 完成交付上线 / Prompt·RAG·Agent 实践”，加分侧是“AI 工具与 Agent 研发经验”。把 AI 只当扩展话题会与一半以上样本脱节。
