## 六、数据库、存储、搜索与消息

| 方向 | 主线/中线 | 扩展生态 | 必学边界 |
| --- | --- | --- | --- |
| 关系数据库 | **PostgreSQL、MySQL**、SQLite | MariaDB、SQL Server、CockroachDB、TiDB、OceanBase | SQL 方言、事务、索引、锁、复制、分区和运维差异 |
| ORM/查询 | Prisma、JPA/Hibernate、MyBatis | Drizzle、TypeORM、Sequelize、Kysely、SQLAlchemy、Django ORM、GORM、sqlc、jOOQ | 生成 SQL、迁移、N+1、事务、连接池和逃生口 |
| 缓存/内存数据 | Redis | Valkey、Memcached | 数据结构、TTL、失效、持久化、集群、热点和一致性 |
| 文档/宽表/键值 | 先用 PostgreSQL JSONB 验证需求 | MongoDB、DynamoDB、Cassandra、ScyllaDB、HBase | 查询模型、分区键、事务、一致性和容量成本 |
| 搜索 | PostgreSQL 全文检索入门 | Elasticsearch、OpenSearch、Meilisearch、Typesense、Algolia | 索引同步、分词、相关性、聚合、重建和故障降级 |
| 分析/时序 | SQL 聚合与窗口函数 | ClickHouse、TimescaleDB、DuckDB、InfluxDB、Apache Druid | OLTP/OLAP 区分、批量写入、压缩、保留和成本 |
| 图数据库 | 关系模型优先 | Neo4j、NebulaGraph | 图遍历是否真的优于关系查询 |
| 对象/文件存储 | 本地受控存储 → S3 兼容模型 | MinIO、云对象存储、CDN | 类型/大小、签名 URL、权限、生命周期、恶意文件和成本 |
| 消息/流 | 持久化后台任务入门 | RabbitMQ、RocketMQ、Kafka、NATS、Pulsar、SQS/Pub/Sub 类云服务 | 至少一次、顺序、重复、积压、重试、死信、消费者幂等 |
| 数据集成 | 定时批处理、Outbox | Debezium/CDC、ETL/ELT、Airflow、Flink、Spark | 数据质量、血缘、重放、Schema 演进和隐私 |
| 向量检索 | pgvector | Qdrant、Milvus、Weaviate、Elasticsearch 向量能力 | Embedding 维度、召回、过滤、评估、更新与成本 |
