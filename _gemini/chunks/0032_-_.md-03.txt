## 六、数字怎么复算

当前唯一资源事实源是 `catalog.json`。本机生成与校验入口：

```text
python 05-外部资料库/tools/catalog_tool.py generate --write
python 05-外部资料库/tools/catalog_tool.py validate --mode strict-mirror
python 05-外部资料库/tools/catalog_tool.py validate --mode source-only
```

- `材料清单.md` 与 `资料索引.md` 的统计区由 catalog 生成，不再手工改数。
- bytes 由原机磁盘扫描得到，MiB/GiB 只做显示；不把四舍五入 MB 反推成精确 bytes。
- 历史时点的 204,641 文件 / 9.67 GB 与 170 仓库账本仅作追溯，不再是当前值。
- 质量与许可边界：下载和镜像不执行第三方脚本；无许可、未识别、GPL/AGPL、CC-NC 资料仅本机学习。
