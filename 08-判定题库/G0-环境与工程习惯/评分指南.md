# G0 评分指南

- 先跑自测脚本：`grade.mjs` 与 `grade-repo.mjs` 全部通过才进入人工复核。
- 机器可读评分见 `评分规则.json`；人工只检查机器未覆盖的部分（改动范围、学习日志），不得用主观印象覆盖测试结果。
- 常见错误清单：
  - 冲突只留一侧（R2 会报缺哪一行）
  - 用 `reset --hard feature/timeout` 代替 merge（R4 父提交数变 1）
  - 顺手 `git add -f config/local.env`（R3 抓秘密入库）
  - 改测试断言让 off-by-one “过”（R6 仍会因断言被改后的真实结果不符）
  - 留 `scratch/` 或半截改动（R1 抓工作树不干净）
- 故障变体见 `故障变体/variant.md`，用于第二套抽测。
