# G0 自评指南

1. 先在 `起始代码/` 里独立完成函数题，不要先看 `参考答案/`。
2. 跑 `node 自测脚本/grade.mjs 起始代码/index.mjs`，记录 checks/fails 与退出码；任何 fail 即函数题未通过。
3. 生成 fixture，在干净 clone 上先跑一次 `grade-repo.mjs`，把**基线失败清单**抄进学习日志（这是「失败先行」的证据）：
   ```bash
   FIX="${TEMP:-/tmp}/g0-fixture"
   node fixture/build.mjs "$FIX"
   git clone "$FIX/legacy.bare.git" "$FIX/learner"
   cd "$FIX/learner" && git checkout main
   node <本包绝对路径>/自测脚本/grade-repo.mjs .
   ```
4. 自己修，再跑一次到 8/8；然后对照 `参考答案/solve-repo.mjs`，写清差异（合并策略、改动范围）。
5. 抽查 1 个 `故障变体/`，确认自测脚本对该缺陷确实报错。
6. 按 `评分规则.json` 的维度给自己打分，把结论与证据路径写进学习日志；不用写给外部评估者。
