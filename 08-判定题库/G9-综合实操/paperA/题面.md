# A 卷 · 预约与排班（公开）

> 12 小时自测的 A 卷。题面、起始代码、种子、故障、答案、自测脚本全部公开。

## 业务规则

一个共享办公空间：多租户、多会议室、按时段预约。

| 规则 | 说明 |
| --- | --- |
| 时段冲突 | 同一房间时间区间重叠 → 只接受先到的一条，其余进 `rejected`（reason=`conflict`） |
| 座位容量 | `slot.seats > room.capacity` → 拒绝（reason=`capacity`） |
| 时区 | 输入时间可能带 `+08:00` 或 `Z`，一律换算成 UTC 毫秒比较 |
| 候补 | 超过房间当日的 `dailyLimit` → 进 `waitlist`（按 `createdAt` 升序） |
| 权限 | `role==='viewer'` → 拒绝（reason=`forbidden`）；跨租户 → 拒绝（reason=`cross_tenant`） |
| 并发 | 同一时刻提交的多条同房间重叠预约，只接受第一条（其余 conflict） |
| 依赖排程 | `dependsOn` 里的预约必须先被接受，否则 `rejected`（reason=`blocked`） |
| 利用率 | `utilization` 返回每房间「已占用分钟 / 当日可预约分钟」（0..1，保留 4 位小数） |
| hold 到期 | `holdUntil` 已过期（相对传入的 `now`）的 hold 视为释放，不占容量 |

## 接口

```js
// 1) 处理一批预约申请
applyBookings({ tenantId, rooms, bookings, now }) -> { accepted, waitlist, rejected }

// 2) 每房间利用率
utilization({ rooms, accepted }) -> { [roomId]: number }

// 3) 释放过期 hold（返回新的 accepted 与 released）
releaseExpired({ accepted, now }) -> { accepted, released }
```

`accepted` 元素形状：`{ id, roomId, start, end, seats, holdUntil? }`（`start/end` 为 UTC 毫秒）。
