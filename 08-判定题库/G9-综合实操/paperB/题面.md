# B 卷 · 订单履约与对账（公开）

> 12 小时自测的 B 卷。题面、起始代码、种子、故障、答案、自测脚本全部公开。

## 业务规则

| 规则 | 说明 |
| --- | --- |
| 库存 | 下单扣减 `stock`；不足 → 拒单（reason=`out_of_stock`），且**不产生任何副作用** |
| 幂等 | 同一 `idempotencyKey` 重复提交 → 返回首次结果（`replayed: true`），库存不再扣 |
| 支付回调 | `paid` 事件按 `eventId` 去重；重复回调不重复入账 |
| 退款 | 已支付才可退；退款额 > 已付额 → 拒绝（reason=`over_refund`） |
| 履约状态机 | `created → paid → shipped → delivered`；`paid` 后可 `refunded`；非法迁移抛错 |
| 对账 | 按订单号把「订单额 / 已付 / 已退 / 库存变动」四账对齐，差异逐条列出 |
| 重复消息 | 同一 `messageId` 的 Outbox 消息只消费一次 |
| 慢查询 | 对账必须单次遍历，禁止嵌套 `find`（用 Map 索引） |

## 接口

```js
// 1) 建单 + 支付回调 + 发货 + 妥投 + 退款，一条事件流
runFlow({ stock, events }) -> { orders: { [orderId]: Order }, stock, effects }

// 2) 对账
reconcile({ orders, payments, refunds, stockMoves }) -> { discrepancies }

// 3) Outbox 去重
consumeOutbox({ messages, delivered }) -> { consumed, skipped }
```

`Order.state` 取值：`created | paid | shipped | delivered | refunded | rejected`。
