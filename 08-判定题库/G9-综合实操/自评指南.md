# G9 自评指南

1. 先读两卷题面，写下自己的验收点清单（不要先看参考答案）。
2. 起计时：
   ```bash
   node 自测脚本/timer.mjs start
   ```
3. A 卷：在 `paperA/起始代码/index.mjs` 里实现，跑到 `14/14`：
   ```bash
   node 自测脚本/grade-paper-a.mjs paperA/起始代码/index.mjs
   ```
   完成时打点：`node 自测脚本/timer.mjs checkpoint A`
4. B 卷：同样跑到 `13/13`，打点 `checkpoint B`。
5. 交叉复测：把 A 卷种子喂给 B 卷实现、B 卷种子喂给 A 卷实现，观察错误语义是否合理（不要求通过，要求**不静默**）。
6. 自评：按 `评分规则.json` 六维逐项打分，写成 JSON 后跑：
   ```bash
   node 自测脚本/score.mjs 我的自评分.json
   ```
7. 结算：`node 自测脚本/timer.mjs finalize`，把输出贴进复盘模板第 5 节。
8. 复盘：按 `复盘模板.md` 写 6 节。两轮都 ≥80 且每维 ≥60% 才算通过。
