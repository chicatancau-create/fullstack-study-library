# G8 评分指南

- 机器断言：`grade.mjs` + `grade-legacy.mjs`（15 条）。任一 fail 即未通过。
- 基线门槛：`--baseline` 必须让 A–G 七组每组至少 1 条 FAIL；否则视为“没有复现缺陷”，不能进入修复阶段。
- 机器可读评分见 `评分规则.json`；人工只看交接文档与自评准确性。
- 常见错误：
  - 直接改 `db/schema.sql` 而不写迁移（生产上不可回滚；应放 `db/migrate_fix.sql`）
  - B 修成「有密钥就用，没密钥也凑一个」（fail open）
  - C 把 `error.message` 回给调用方（仍然泄露表名与 SQL 片段）
  - E 只加 `id` 到 ORDER BY 但分页仍用 OFFSET
  - G 把搜索改成不可索引的 `LOWER(title) LIKE '%x%'`
  - 交接文档只列“我改了什么”，没有运行手册与未修复项
- 故障变体见 `故障变体/variant.md`（7 组，`npm run evidence` 自动复现）。
