# G8 自评指南

1. 先独立做函数题：
   ```bash
   node 自测脚本/grade.mjs 起始代码/index.mjs
   ```
2. 失败先行（必须做，这是本关的核心方法）：
   ```bash
   bash scripts/db_setup.sh
   node 自测脚本/grade-legacy.mjs 起始代码/src/legacy.mjs --baseline
   ```
   把 `baseline groups A:1/1 B:1/3 ...` 这行抄进交接文档；某一组没有 FAIL 就说明你还没看懂结构。
3. 逐项修 7 个缺陷，每修一组重跑一次；先修安全类（A/B/C/F），再修数据一致性（D/E），最后修查询（G）。
4. 跑满 15/15 后，连跑 3 次：并发题偶发通过就是没修好。
5. 写交接文档（`交接模板.md` 6 节），自评按「缺陷修复率 / 交接文档质量 / 自我评估准确度」打分。
6. 按 `评分规则.json` 给总分，结论与证据路径写进学习日志。
