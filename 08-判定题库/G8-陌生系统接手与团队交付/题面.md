## 题 2 · 接手固定旧系统

`起始代码/src/legacy.mjs` 是一份「交接时留下的」代码，含 7 个公开缺陷（A–G 见 `README.md`）。
`db/schema.sql` 是遗留结构（`task` 无 `version`、只有 `created_at` 单列索引）。

### 第一步：失败先行（必须先做）

```bash
bash scripts/db_setup.sh
node 自测脚本/grade-legacy.mjs 起始代码/src/legacy.mjs --baseline
```

`--baseline` 要求 **A–G 七组每组都有 FAIL**；把这份输出抄进交接文档，作为“缺陷确实存在”的证据。

### 第二步：逐项修复

```bash
node 自测脚本/grade-legacy.mjs 起始代码/src/legacy.mjs      # 目标 15/15
```

修复要点（不解这 7 条不算完成）：

- **A** refresh 轮换要条件更新（`rotated_at IS NULL` 守卫）并吊销旧 token。
- **B** 没有 `JWT_SECRET`（≥16 字符）时必须**拒绝签发**，不能退回常量。
- **C** 对外只回稳定错误码，stack 只进服务端日志。
- **D** `db/migrate_fix.sql` 加 `version` 列；更新带 `AND version = ?`，冲突返回 `{conflict:true, current}`。
- **E** 排序改成 `(created_at DESC, id DESC)`，分页改 keyset（cursor = 上一页最后一条 id）。
- **F** `getTask` 必须带 `tenant_id`。
- **G** 搜索改成前缀 `LIKE $2 || '%'`，并确保 `idx_task_title_prefix` / `idx_task_stable` 存在。
