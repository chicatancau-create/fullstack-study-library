# G4 题面

两道子题：RBAC 判定函数 + 真实数据库读写。

## 题 1 · 租户隔离 + RBAC

实现 `canAccess(member, action, resource)`：

- 跨租户一律 `false`（`resource.tenantId !== member.tenantId`）
- `read`：`owner` / `admin` / `member`
- `write`：`owner` / `admin`
- `manage`：仅 `owner`
- 未知 action → `false`

```bash
node 自测脚本/smoke.mjs
node 自测脚本/grade.mjs 起始代码/index.mjs
```

## 题 2 · 真实 PostgreSQL

`起始代码/db/access.mjs` 有 4 处真实缺陷，逐条修到 `grade-db.mjs` 10 条断言全过：

1. **跨租户越权**：`listTasks` 只按 `projectId` 过滤，漏了 `tenant_id`。
2. **SQL 注入**：`searchTasks` 把用户输入拼进 SQL。
3. **丢失更新**：`updateTaskTitle` 不校验 `version`，并发下互相覆盖。
4. **分页不稳**：用 `OFFSET` 翻页，插入新行后会重复/漏页。

```bash
bash scripts/db_setup.sh          # 建 g4_lab + 种子 + 迁移回滚演练
node 自测脚本/grade-db.mjs 起始代码/db/access.mjs
```

数据库默认连本机 `study_lab`（`PGUSER=study` / `PGPASSWORD=study-pass`），只碰 `g4_lab` schema。

额外要求：
- `updateTaskTitle` 成功后 `version` 必须 +1；失败返回 `null`（不要抛错）。
- `listTasks` 用 keyset 分页：接口参数从 `offset` 改为 `cursor`。
- 补一个 `renameProjectAtomically`：两个写在同一事务里，第二个失败必须整笔回滚。
