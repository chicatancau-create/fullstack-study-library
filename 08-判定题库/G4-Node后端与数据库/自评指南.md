   ```bash
   node 自测脚本/grade.mjs 起始代码/index.mjs
   ```
2. 准备数据库并跑基线，把每条 fail 抄进学习日志（失败先行）：
   ```bash
   bash scripts/db_setup.sh
   node 自测脚本/grade-db.mjs 起始代码/db/access.mjs
   ```
   基线预期：8 条 fail（D1/D3/D4/D5/D6/D7/D8/D9），D2 通过。

   - `updateTaskTitle` 返回 `null` 表示版本冲突，不抛错

6. 按 `评分规则.json` 给自己打分，把结论与证据路径写进学习日志。
