# G4 评分指南

- 先跑机器断言：`grade.mjs`（函数题）+ `grade-db.mjs`（数据库 10 条）。任一 fail 即本关未通过。
- 机器可读评分见 `评分规则.json`；人工只检查两点：改动范围、学习日志能否复跑。
- 常见错误：
  - 只在应用层过滤租户，SQL 里没有 `tenant_id`（D1 会读到 t2 的数据）
  - 用模板字符串拼 SQL，靠“输入看起来安全”兜底（D3/D4 会真注入）
  - 乐观锁写成 `SET version = version + 1 WHERE id = ...` 但不带 `AND version = $n`（D5/D7 抓）
  - 用 `RETURNING` 判断成功但没检查行数，返回 `{}` 而不是 `null`（D5 抓返回值）
  - 分页仍用 `OFFSET`（D8 抓重复/漏页）
  - 事务用 `pool.query` 三次而不是同一个 `client`（D9 抓回滚失效）
  - 把 `study_lab` 里的其它 schema 当实验区（破坏环境，属于越界）
- 故障变体见 `故障变体/variant.md`（4 条，`npm run evidence` 自动复现）。
