# 08-判定题库

> MS3 交付区：G0–G9 十个关口的判定题包。每个包含 `学生包/`、`教师包/`、`评分指南` 与可自动判定的隐藏测试。

## 结构与隔离

- **学生包**：题面、起始代码、公开冒烟测试。只把这一层交给被评估者。
- **教师包**：隐藏测试、答案密钥、评分指南、故障变体。不得进入学生仓库。
- 判定入口统一：`npm run evidence`（`bash scripts/evidence.sh`），同时验证“答案密钥通过、起始代码被拒绝”。

## 边界

- 这些包判定的是各关口**可自动断言的核心子项**，不替代完整项目、口头答辩与外部评估；通过判定包不等于 G 关口自动通过。
- 评分以隐藏测试为准，人工只复核测试未覆盖的边界与改动范围。
- 故障变体用于第二套抽测，确认测试有牙齿。
