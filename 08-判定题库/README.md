# 08-判定题库

> 自学自测区：G0–G9 十个关口的学习包。题面、起始代码、参考答案、自测脚本、评分指南**全部公开**，学习者自己读题、自己做、自己对照、自己评分。

## 结构与使用

每个关口目录统一为：

```
Gx/
├── README.md      本关说明、任务、rubric、边界
├── 题面.md        题面与要求
├── 起始代码/      从这里开始
├── 参考答案/      做完后对照
├── 自测脚本/      smoke + grade，自己跑
├── 故障变体/      第二套练习
├── 评分指南.md    自评 rubric
└── 自评指南.md    自评步骤
```

- 推荐顺序：读 `题面.md` → 写 `起始代码/` → 跑 `自测脚本/` → 对照 `参考答案/` → 按 rubric 自评。
- 证据入口统一：`npm run evidence`（`bash scripts/evidence.sh`），同时验证“参考答案通过、起始代码被拒绝”。
- 本区不含教师端/学生端隔离与防作弊设计；答案公开是自学设计的一部分。

## 边界

- 这些包只覆盖各关口**可自动断言的核心子项**，不替代完整项目、口头答辩或外部评估；自测通过不等于 G 关口自动通过。
- 自评以 `自测脚本/grade.mjs` 为准，rubric 用于定位薄弱点；答案与脚本全部公开，不构成防作弊考试。
- 故障变体用于第二套练习，确认自测脚本对该缺陷确实报错。
