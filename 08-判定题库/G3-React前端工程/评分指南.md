# G3 评分指南

- 机器断言：`grade.mjs`（函数题）+ `grade-react.mjs`（6 条）+ `grade-build.mjs`（4 条）。任一 fail 即未通过。
- 机器可读评分见 `评分规则.json`；人工只看改动范围与学习日志。
- 常见错误：
  - 用 `setTimeout` 猜顺序（网络抖动就复现不了，R3 仍会抓）
  - 只在 `onChange` 里防抖，却没丢弃过期响应（R3 抓的是“谁后到谁生效”）
  - `memo` 的比较函数写 `() => true` 或只比 `id`（R4 抓）
  - 用 `placeholder` 当可访问名（R5 会报“没有可访问名”）
  - 把 `base` 改成 `"/"`（B2 抓绝对路径）
  - 为“提速”内联一个 500kB 依赖（B4 抓体积）
- 故障变体见 `故障变体/variant.md`。
