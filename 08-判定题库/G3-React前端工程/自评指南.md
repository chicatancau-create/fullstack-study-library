# G3 自评指南

1. 先独立做函数题，不要先看参考答案：
   ```bash
   node 自测脚本/grade.mjs 起始代码/index.mjs
   ```
2. 装应用依赖并跑基线，把每条 fail 抄进学习日志：
   ```bash
   cd 起始代码/app && npm install && npm run build && cd ../..
   node 自测脚本/grade-react.mjs 起始代码/app
   node 自测脚本/grade-build.mjs 起始代码/app
   ```
   基线预期：组件级 3 条 fail（R3/R4/R5），构建级 4 条全过。
3. 改 `src/main.jsx` 逐条修，每修一条重跑一次；改完 `npm run build` 再跑（grader 读的是 `dist/`）。
4. 对照 `参考答案/app/src/main.jsx`，写清差异：
   - 竞态用请求序号还是 `AbortController`，为什么选这个
   - `memo` 的比较函数为什么不能只比 `id`
   - 可访问名用 `<label for>` 还是 `aria-label`
5. 抽查 2 个 `故障变体/`，确认 `grade-react.mjs` 确实报错。
6. 按 `评分规则.json` 给自己打分，把结论与证据路径写进学习日志。
