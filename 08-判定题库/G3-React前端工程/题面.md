# G3 题面

两道子题：一个竞态保护函数，一个真实 Vite React 应用。

## 题 1 · 竞态保护函数

实现 `latestOnly()`：返回一个包装函数，只接受最后一次调用的结果。

```js
const guard = latestOnly();
const p1 = guard(slow(900, 'a'));   // 先发
const p2 = guard(fast(380, 'al'));  // 后发
await Promise.all([p1, p2]);
// p1 必须返回 { stale: true, value: null }，p2 才是 { stale: false, value: ... }
```

要求：
1. 不引入新依赖；Node 24 可直接运行。
2. 边界与失败路径要有明确结果，不静默吞错。
3. `自测脚本/grade.mjs` 与 `参考答案/index.mjs` 都已公开，做完再对照。

```bash
node 自测脚本/smoke.mjs
node 自测脚本/grade.mjs 起始代码/index.mjs
```

## 题 2 · 真实 Vite React 应用（3 个缺陷）

`起始代码/app/` 是一个能跑的 React 19 + Vite 8 应用。它有三个缺陷：

1. **请求竞态**：`useEffect` 里谁后到谁生效，短查询的慢响应会覆盖长查询的结果。
2. **memo 比较函数吞更新**：`TaskRow` 被 `memo` 包住，比较函数只比 `id`，于是点击切换后 `aria-pressed` 不更新。
3. **可访问性**：输入框没有可访问名。

修到这两条都全绿：

```bash
cd 起始代码/app && npm install && npm run build && cd ../..
node 自测脚本/grade-react.mjs 起始代码/app     # 6 条：R1/R2/R3/R4/R5/R7
node 自测脚本/grade-build.mjs 起始代码/app     # 4 条：B1/B2/B3/B4
```

基线预期：`grade-react` 有 3 条 fail（R3 竞态、R4 memo、R5 可访问性），`grade-build` 4 条全过（构建本身没问题）。
