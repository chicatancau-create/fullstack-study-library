# G1 题面

四道子题，都围绕「Web 基础 + 机器可验证」。

## 题 1 · 静态可访问性检查函数

实现 `a11yIssues(html)`，返回问题 id 数组（顺序固定：`html-lang`、`img-alt`、`input-label`、`viewport`）。

```bash
node 自测脚本/smoke.mjs
node 自测脚本/grade.mjs 起始代码/index.mjs
```

## 题 2 · 真站点（5 类缺陷）

`起始代码/site/index.html` 里埋了 5 类缺陷，逐条修到 `grade-site.mjs` 全绿：

1. 低对比度文字
2. `img` 缺 `alt`
3. `<label for>` 指向不存在的 id（输入框没有可访问名）
4. 表格用 `td` 当表头
5. 用 `div` + `onclick` 假按钮

```bash
npm install
npx playwright install chromium-headless-shell
node 自测脚本/grade-site.mjs 起始代码/site/index.html   # 先看基线失败
node 自测脚本/grade-site.mjs 起始代码/site/index.html   # 修完再跑到 6/6
```

## 题 3 · HTTP 服务（5 处协议缺陷）

`起始代码/server.mjs` 里改了 5 处：

1. 响应没有 `content-type`
2. 非 GET 没返回 405 + `Allow`
3. CORS 无条件回显任何 `Origin`
4. 没有 `ETag` / `304` 协商缓存
5. 不存在的单项返回 200 + 空对象

```bash
node 自测脚本/grade-http.mjs 起始代码/server.mjs
```

## 题 4 · C 环形缓冲（2 处内存缺陷）

`起始代码/c/ring_buffer.c` 里有两处：

1. 满时没有检查就写，越界
2. `int index` 用 `size_t` 比较，负数被转成巨大值绕过边界

```bash
bash scripts/run_c.sh 起始代码/c/ring_buffer.c "$TEMP/g1c"
```
