# G1 自评指南

1. 先独立做函数题（`起始代码/index.mjs`），不要先看 `参考答案/`。
2. 依次跑四题的**基线**，把每个 fail 抄进学习日志（这是「失败先行」的证据）：
   ```bash
   node 自测脚本/grade.mjs 起始代码/index.mjs
   node 自测脚本/grade-site.mjs 起始代码/site/index.html
   node 自测脚本/grade-http.mjs 起始代码/server.mjs
   bash scripts/run_c.sh 起始代码/c/ring_buffer.c "${TMPDIR:-/tmp}/g1c"
   ```
3. 逐题修，每题修完再跑一次，直到 `checks=… fails=0`。
4. 对照参考答案，写清差异：
   - 站点：alt 是描述性的还是空的；焦点样式怎么给的
   - HTTP：304 的判定条件；CORS 白名单怎么表达；405 的 `Allow`
   - C：满时返回值约定；负索引在无符号比较前怎么挡
5. 抽查 2 个 `故障变体/`，确认对应 grader 真的报错。
6. 按 `评分规则.json` 给自己打分，结论与证据路径写进学习日志。
