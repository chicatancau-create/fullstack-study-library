# G1 评分指南

- 先跑通四题的机器断言：`grade.mjs`、`grade-site.mjs`、`grade-http.mjs`、`run_c.sh`；任一 fail 即未通过。
- 机器可读评分见 `评分规则.json`；人工只看两件事：改动范围、学习日志能否复跑，不得覆盖机器结论。
- 常见错误：
  - 站点题只加 `alt=""`（空 alt 仍被 A3 抓；装饰图应 `role="presentation"` 或说明性 alt）
  - 用 `tabindex="-1"` 让 Tab 跳过控件（A5 会少一个可达控件）
  - CORS 用 `*` 通配 —— 白名单与非白名单的差异就看不出来了（H7 直接抓）
  - “有 200 就算成功” —— H4/H5/H6 会分开报
  - C 题把 `index` 改成 `size_t` —— 负索引变成巨大值，仍然会读到越界内存（C2 变体验证过）
- 故障变体见 `故障变体/variant.md`。
