# 国内大厂真题

> 六家公司各 ≥30 题，全部来自公开面经统计。**没有公司发布官方题库**；`真题` 只表示题面可追溯到公开面经，不是官方认证。

合计 250 题。CodeTop 的数据说明见其上游 [LeetcodeTop](https://github.com/afatcoder/LeetcodeTop)（“频度数据都是我人工整理面经而得”）；本目录只引用题名、链接、热度和最后出现时间。

## 每题字段

公司、岗位、时间（由最后出现时间换算季度）、来源、来源 URL、可信度、是否真题；题面给出 LeetCode 链接。

## 维护

- 每季度用同一 API 复核一次，更新题名、链接与热度。
- 链接失效时标注 `已失效` 并保留原 URL，不删除记录。
- 新增题目必须先登记来源；找不到来源的只能标 `模拟题`。

## 边界

- `真题（面经统计，非官方）` 不能被引用为“公司官方确认考过”。
- 热度是面经统计，不是考察概率；不同岗位与年份差异很大。
- 本目录不转载题解正文。

## 字段分离与质量门禁

`_工具/` 已把 250 题拆出 `question_url`（题面）、`aggregate_source_url`（CodeTop 聚合）与 `primary_evidence`（原始面经），并把岗位统一标为“岗位未标注”而非默认后端。当前已核验公开牛客面经 3 条、覆盖 2 道题（Q002、Q067），其余 248 题仍为第三方聚合；3 条链接均通过标题匹配与软 404 复验（3/3）。采集尝试（含登录墙/仅作者可见的失败记录）见 `_工具/evidence/evidence-collection-log.json`，遇登录即停、不绕过。质量门禁 6/6 通过；运行方式见 `_工具/README.md`。

## 前端 / 全栈补充题

`前端全栈/` 补齐 16 道面向原岗位方向的题（前端 10、全栈 6，覆盖 React、JS、CSS、浏览器、可访问性、SSR、构建、性能、Node、缓存、SQL、契约、部署、故障）。每题含专属答案、评分点与追问，来源为 React/MDN/Node/PostgreSQL 官方文档；**没有原始面经，全部标为模拟题**。质量门禁 `_工具/check_frontend.mjs` 当前 5/5 通过。

## 公司×岗位×题型矩阵

`岗位矩阵.csv` 由 `_工具/build_role_matrix.mjs` 从各公司 `题目索引.json` 与 `前端全栈/questions.json` 生成：算法题 250 道（岗位未标注）、前端 10 道、全栈 6 道，共 266 道。`_工具/evidence/role-matrix.json` 同时记录 `verified_raw_evidence = 3`（3 条证据覆盖 2 道题），其余仍按聚合来源标记，不冒充已核验真题。
