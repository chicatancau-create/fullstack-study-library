## 来源与可信度

- **字节跳动 / 腾讯 / 阿里巴巴 / 美团**：题目来自 [LeetcodeTop](https://github.com/afatcoder/LeetcodeTop)，该仓库作者声明“频度数据都是我人工整理面经而得”，原始文章链接放在其 issues。题目链接指向 LeetCode；上游记录的次数只是面经统计。
- **滴滴 / 华为**：未找到可公开核验的题源，30 题全部标为 `模拟题`，来源 URL 仅为招聘官网的岗位背景，不作为题面证据。
- 每题都带：公司、岗位、时间、来源、来源 URL、可信度、是否真题。

## 维护

- 每季度检查一次来源链接；失效链接改为 `已失效` 并保留原 URL，不删除记录。
- 新题先登记来源再入库；找不到来源的只能标 `模拟题`。
- 修改记录追加到本文末尾的 changelog。

## 边界

- `真题（面经统计，非官方）` 不能被引用为“公司官方确认考过”。
- 模拟题只用于练习表达与设计，不构成任何公司面试事实。
- 本目录不转载题解正文，只给作答要求与链接。
