## 题 2 · 真实交易库

`起始代码/db/trade.mjs` 有 4 处真实缺陷：

1. **超卖**：先 `SELECT available` 再 `UPDATE`，100 并发能卖出 100 件。
2. **幂等失效**：幂等键只在进程内存 `Map` 里，并发同键会建两单。
3. **对账漏项**：只比订单额与支付额，不看拒单是否有支付。
4. **失败伪装成功**：库存不足仍返回 `ok: true`。

```bash
bash scripts/db_setup.sh
node 自测脚本/grade-trade.mjs 起始代码/db/trade.mjs     # 目标 15/15
```

额外要求：

- 扣库存必须条件化：`WHERE sku = $2 AND available >= $1`，`rowCount === 0` 即失败并回滚。
- 幂等用 `ON CONFLICT (idempotency_key) DO NOTHING RETURNING id`；重放返回 `replayed: true`。
- 并发同键可能撞 `23505` / `40P01` / `40001`：最多重试 3 次，不要把瞬时冲突当业务失败。
- 对账要能报出 `paid_mismatch` 与 `paid_rejected`，并带 `expected` / `actual`。
- 补 `capacityEstimate({requests, concurrency, msPerRequest})`：返回 `rps` / `wallMs` / `saturation`，非法参数抛 `RangeError`。
