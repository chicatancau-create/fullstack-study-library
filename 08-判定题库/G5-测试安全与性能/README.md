# G5 测试安全与性能

> MS3 判定题包。学生只拿 `学生包/`；`教师包/` 不得下发。

## 任务

输入校验：数量、SKU 格式、XSS 字符。函数签名：`validateOrder(input)`。

## 判定

- 隐藏测试：`node 教师包/隐藏测试/grade.mjs <候选模块路径>`
- 证据：`npm run evidence`（等价于 `bash scripts/evidence.sh`），会验证“答案密钥通过、起始代码被拒绝”。

## 评分 rubric

| 维度 | 0 | 1 | 2 | 3 |
| --- | --- | --- | --- | --- |
| 核心不变量 | 未实现 | 部分路径 | 主路径正确 | 主路径 + 边界/反例 |
| 失败处理 | 静默吞错 | 抛错但无上下文 | 明确错误 | 可复现 + 回归测试 |
| 可读性 | 无法读 | 命名混乱 | 结构清楚 | 小而清晰、无冗余 |
| 隐藏测试 | 0 通过 | 部分通过 | 全部通过 | 全部通过且改动最小 |

硬门槛：隐藏测试全部通过；否则本关不通过。评分只由 `教师包/隐藏测试/grade.mjs` 与评估者复核共同决定，学生自评不计分。


## 边界

- 本包只判 G5 的核心可自动断言部分，不替代完整项目、口头答辩与外部评估。
- 学生包与教师包物理隔离；评估者不得把教师包放进学生仓库。
