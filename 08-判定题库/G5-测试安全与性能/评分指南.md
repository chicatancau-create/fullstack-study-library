# G5 评分指南

- 机器断言：`grade.mjs`（函数题）+ `grade-trade.mjs`（15 条）。任一 fail 即未通过。
- 机器可读评分见 `评分规则.json`；人工只看改动范围与学习日志。
- 常见错误：
  - 先 `SELECT available` 再 `UPDATE`（T1 直接跑出 100 成功）
  - 幂等键存在应用内存 `Map`（并发同键建两单，T2 抓）
  - `ON CONFLICT DO NOTHING` 后不区分“是我插入的”和“别人先插的”（重放返回 `id: null`，T2 计数抓）
  - 并发同键撞 `23505` 直接当失败返回（需要有限重试；实测出现过 4/5）
  - 对账用嵌套 `find` / 只比总额（T5/T6 抓）
  - 缺货返回 `ok: true`（T3 抓）
- 故障变体见 `故障变体/variant.md`（4 条，`npm run evidence` 自动复现）。
