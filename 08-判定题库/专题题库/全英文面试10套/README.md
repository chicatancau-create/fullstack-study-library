# 全英文面试 10 套

> 每套 60 分钟，全程英文。用于面试表达训练与同行互评，不是企业录用结论。

## 结构

| 目录 | 内容 |
| --- | --- |
| `题包/SET-01.md`–`SET-10.md` | 每套含自我介绍（5 min）、技术问答（25 min）、现场编码（20 min，算法 + API 设计）、行为面试（10 min） |
| `评分指南/rubric.md` | 发音、流利度、技术准确度、沟通结构四维 1–5 分与权重 |
| `录音脚本/评分记录模板.md` | 评估者逐段计时、引用原话、记录代码与红线的模板 |
| `web/` | 可执行的自测页面：抽题、60 分钟分段计时、本地录音、四维打分、红线封顶、导出 JSON |
| `tests/core.test.js` | 计时分段、抽取、加权分与红线逻辑的单元测试 |
| `scripts/evidence.sh` | 语法检查 + 单元测试，产出 `evidence/` |

## 使用方式

### 网页自测（推荐）

```bash
npm run test        # 计时分段 / 抽取 / 加权分 / 红线逻辑
npm run evidence    # 语法检查 + 单元测试，写 evidence/
npm run serve       # http://127.0.0.1:8099
```

页面提供：随机抽一套题与追问、60 分钟分段计时（5/25/20/10，可暂停/重置）、
浏览器本地录音（MediaRecorder，停止后仅可下载到本机）、四维 1–5 打分、
红线勾选后按封顶规则折算、备注、导出 JSON 记录、删除本地记录。

### 线下互评

1. 选一套，评估者按题包逐段提问并录音（需被评估者同意）。
2. 按 `rubric.md` 四维打分，至少为低于 3 分或高于 4 分的维度各记两条原话证据。
3. 用 `评分记录模板.md` 记录分段耗时、代码是否运行、行为面试 STAR 要素。
4. 反馈只讲两个下次要练的点，避免泛泛而谈。

## 边界

- 题包不提供逐字稿或"标准答案"：技术问答看的是权衡与失效模式，不是背诵；
  评分 rubric 与红线规则全部公开，供自学者自行对照。
- 评分是本地练习口径，不构成语言能力认证或招聘决定。
- 录音只在浏览器内产生并留在本机，不上传仓库或第三方；记录的删除由学习者自己操作。
- 网页计时靠浏览器时间戳，切后台或休眠可能导致分段偏差，恢复后以页面显示为准。
