# 全英文面试 10 套

> 每套 60 分钟，全程英文。用于面试表达训练与同行互评，不是企业录用结论。

## 结构

| 目录 | 内容 |
| --- | --- |
| `题包/SET-01.md`–`SET-10.md` | 每套含自我介绍（5 min）、技术问答（25 min）、现场编码（20 min，算法 + API 设计）、行为面试（10 min） |
| `评分指南/rubric.md` | 发音、流利度、技术准确度、沟通结构四维 1–5 分与权重 |
| `录音脚本/评分记录模板.md` | 评估者逐段计时、引用原话、记录代码与红线的模板 |

| SET-10 | 单体迁移 | Senior |

## 使用方式

1. 选一套，评估者按题包逐段提问并录音（需被评估者同意）。
2. 按 `rubric.md` 四维打分，至少为低于 3 分或高于 4 分的维度各记两条原话证据。
3. 用 `评分记录模板.md` 记录分段耗时、代码是否运行、行为面试 STAR 要素。
4. 反馈只讲两个下次要练的点，避免泛泛而谈。

## 边界

- 题包不提供逐字稿或"标准答案"：技术问答看的是权衡与失效模式，不是背诵。
- 评分是本地练习口径，不构成语言能力认证或招聘决定。
- 录音与记录仅留在本机，不上传仓库或第三方；反馈结束后删除，除非被评估者要求保留。
