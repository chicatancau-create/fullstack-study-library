# 后端实操 30 题 · 评分指南

## 计分

- 每题 1 分，满分 30 分。
- 计分条件：`IMPL=solution/index.mjs` 时隐藏测试退出码 0，且 `IMPL=starter/index.mjs` 时退出码非 0。
- 通过线建议 24 分；分类得分单独记录，用于定位薄弱域。

## 分类权重

| 分类 | 题号 | 分值 | 观察点 |
| --- | --- | --- | --- |
| API 契约 | A01–A08 | 8 | 兼容性判断是否把"删除必填字段/改类型"判为破坏性变更 |
| 对象级授权 | B01–B08 | 8 | 跨租户是否先于 owner/admin 判断被拒绝 |
| Owner 并发 | C01–C06 | 6 | 版本冲突、重试上限、同 Key 串行是否符合预期 |
| Outbox 与消息 | D01–D04 | 4 | 幂等键、退避上限、死信边界 |
| JVM 诊断 | E01–E04 | 4 | 解析容错、死锁环检测、状态计数 |

## 判定流程

1. 复制学生包（题面 + starter）到独立目录，不提供 solution 与 hidden。
2. 学生完成后，教师在原始目录执行 `npm run test:hidden`。
3. 记录 `evidence/judge.txt`；任一题 `starter_exit=0` 说明起始代码未真正失败，该题不计分并复核题目。
4. 人工只复核隐藏测试未覆盖的行为边界：空输入、跨租户优先级、错误码、是否修改入参。

## 边界

- 这些题验证的是可自动断言的核心逻辑，不替代 P02/P03 的真实数据库、事务、压测与部署证据。
- E01–E04 为日志/采样/线程图解析题，用 JavaScript 实现，不构成真实 JVM 调优经历。
- 隐藏测试与学生包物理隔离；不得把 `hidden/` 或 `solution/` 分发给被评估者。
