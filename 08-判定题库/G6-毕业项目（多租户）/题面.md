## 题 2 · 多租户脚手架

`起始代码/db/tenant.mjs` 有 4 处真实缺陷：

1. **跨租户越权写**：`updateTask` 只按 `id` 更新。
2. **审计缺 before**：只记 after，也没有校验操作者。
3. **批量遇错整体崩**：`batchAssign` 第一项失败就 `throw`。
4. **软删仍可见**：`listTasks` 不过滤 `deleted_at`。

```bash
bash scripts/db_setup.sh
node 自测脚本/grade-tenant.mjs 起始代码/db/tenant.mjs     # 目标 14/14
```

额外要求：

- `listTasks` 返回 `{ ok, rows }`；无权访问返回 `{ ok:false, reason:'forbidden' }`。
- `updateTask` 先用 `SELECT ... FOR UPDATE` 取 before（带 `tenant_id`），再乐观锁更新，最后同一事务写审计（before + after + who）。
- `batchAssign` 需要 `admin` 及以上；返回逐项 `{id, ok, reason?}`，不要整体抛错。
- 补 `expandSchema()`：给 `task` 加可空列 `due_at`，旧查询必须仍可用。
