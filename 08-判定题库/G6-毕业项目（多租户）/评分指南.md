# G6 评分指南

- 机器断言：`grade.mjs`（函数题）+ `grade-tenant.mjs`（14 条）。任一 fail 即未通过。
- 机器可读评分见 `评分规则.json`；人工只看改动范围与学习日志。
- 常见错误：
  - 只在 `req.tenantId` 层过滤，SQL 里没有 `tenant_id`（G3 会改到 Globex 的任务）
  - 审计在 `COMMIT` 之后单独插（崩溃时审计丢失；G5 依赖同一事务的 before/after）
  - 批量用 `Promise.all` 且不 catch（G6 抓：一项失败整体 reject）
  - 软删用硬删代替（G2 抓：`includeDeleted` 看不到历史）
  - expand 直接改列类型而不是加可空列（G8 抓：旧查询断）
- 故障变体见 `故障变体/variant.md`（5 条，`npm run evidence` 自动复现）。
