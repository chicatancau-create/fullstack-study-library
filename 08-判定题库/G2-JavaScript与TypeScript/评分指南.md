# G2 评分指南

- 机器断言：`grade.mjs`（2）+ `grade-ts.mjs`（16）+ `grade-cli.mjs`（14）+ `tsc` + `type-coverage`。任一 fail 即未通过。
- 机器可读评分见 `评分规则.json`；人工只看改动范围与学习日志。
- 常见错误：
  - `pump()` 用 `<= limit` 而不是 `< limit`（峰值溢出，grade-ts 抓）
  - 失败分支忘记 `pump()`（一个任务抛错后队列卡死）
  - `queueMax` 用 `>` 判断（多放一个，`queue_full` 不触发）
  - `stats()` 直接返回内部 state（外部改快照污染状态）
  - CLI 未知参数不报错、`--limit` 缺值给默认值（退出码应为 2）
  - schema 错误与执行失败混用同一个退出码（应 3 与 4）
  - 取消只在入口检查一次（已启动任务仍 `ok`）
- 故障变体见 `故障变体/variant.md`（4 条，`npm run evidence` 自动复现）。
