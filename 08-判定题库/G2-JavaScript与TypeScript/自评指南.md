# G2 自评指南

1. 先独立做函数题（`起始代码/index.mjs`），不要先看参考答案：
   ```bash
   node 自测脚本/grade.mjs 起始代码/index.mjs
   ```
2. TS 池基线（会看到 NOT_IMPLEMENTED）：
   ```bash
   node 自测脚本/grade-ts.mjs 起始代码/ts/pool.ts
   npx tsc -p tsconfig.json
   npx type-coverage --project tsconfig.json --at-least 80
   ```
3. CLI 基线（14 条里大部分会因为未实现而失败）：
   ```bash
   node 自测脚本/grade-cli.mjs 参考答案/ts/cli.ts    # 先用答案跑通，确认环境
   ```
   然后把自己写的 `起始代码/ts/cli.ts` 作为第二个参数跑同一套断言。
4. 修到三条 grader 全绿 + `tsc` 零错 + `type-coverage` ≥80%；类型层断言在 `类型测试/pool.test-d.ts`，改实现后要重跑 `tsc`。
5. 连跑 3 次 `grade-cli.mjs`：并发/取消用例偶发通过就是没修好。
6. 按 `评分规则.json` 打分，结论与证据路径写进学习日志。
