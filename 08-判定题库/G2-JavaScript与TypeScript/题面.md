## 题 1 · JS 有界异步池

实现 `createPool(limit)`：有界异步池，并发上限、FIFO、拒绝后继续。

要求：
1. 不引入新依赖；Node 24 可直接运行。
2. 边界与失败路径要有明确结果，不静默吞错。
3. 运行公开冒烟：`node 自测脚本/smoke.mjs`（只做冒烟）。
4. `自测脚本/grade.mjs` 与 `参考答案/index.mjs` 都已公开，做完再对照，不要先看。

## 题 2 · TS CLI（陌生代码阅读 + 补齐）

`参考答案/ts/cli.ts` 是完整参考实现；你要在 `起始代码/ts/` 下自己写出来：

- `createPool(limit, queueMax?)` —— 返回 `{ run, stats }`，`stats()` 快照含 `peak/running/queued`。
- `parseArgs(argv)` —— 支持 `--limit N`、`--queue N`、`--json`、`--help`；无参数/未知参数/非法取值抛 `UsageError`。
- `validateJobs(raw)` —— 顶层必须是数组，每项 `id` 非空字符串、`ms` 非负数，否则抛 `SchemaError`。
- `runJobs(jobs, { limit, queue, signal })` —— 每个任务都有终态：`ok` / `cancelled` / `error`；取消通过 `AbortSignal`。
- `main(argv)` 退出码约定：`0` 全部成功 · `2` 用法错误 · `3` schema 错误 · `4` 池执行失败 · `130` 被中断。

要求：
1. 只改 `起始代码/ts/`，不要改 `参考答案/`（那是答案）。
2. `tsc -p tsconfig.json` 必须零错误；`type-coverage` ≥80%。
3. 队列满时立即拒绝（错误信息含 `queue_full`），已在跑的任务不受影响。
4. 运行 `node 自测脚本/grade-ts.mjs 起始代码/ts/pool.ts` 与 `node 自测脚本/grade-cli.mjs` 自测；两条都过再对照 `参考答案/ts/`。
