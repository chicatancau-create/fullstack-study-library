# G7 评分指南

- 机器断言：`grade.mjs` + `grade-mysql.mjs`（7 条）。任一 fail 即未通过。
- 机器可读评分见 `评分规则.json`；人工只看改动范围与学习日志。
- 常见错误：
  - 用 `@@transaction_isolation` 判“切成功”（MySQL 8 事务内仍显示全局值，假绿）
  - 先 `SELECT available` 再 `UPDATE`（10 并发订 5 件跑出 -5）
  - `SELECT ... FOR UPDATE` 写在事务外（锁立刻释放）
  - 乐观锁 `UPDATE` 不带 `AND version = ?`（M4 跑出 10/10 赢）
  - `deadlockDemo` 两条连接按同一顺序加锁（永远不会 1213）
- 故障变体见 `故障变体/variant.md`（4 条，`npm run evidence` 自动复现）。
