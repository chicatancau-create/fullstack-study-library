# 项目长期约定

- 本库是全栈工程师学习与项目复盘库，正式入口为 `000-学习总览.md`。
- 默认路线为“36 周主线 + 16 周中线 + 长期专项”，每周 12–15 小时，可顺延但不能通过删除测试、权限、数据约束和复盘赶进度。
- P0 主技术栈：TypeScript、React/Vite、Node.js/Fastify、PostgreSQL/SQL/Prisma、Redis、Vitest/Testing Library/Playwright、Docker/GitHub Actions。
- P1 中技术栈：Java/JVM、Spring Boot/Spring Security、Vue 3/Router/Pinia、MySQL、JPA/Hibernate/MyBatis、JUnit/Testcontainers；另纳入 Spring Cloud Alibaba、Dubbo、Nacos、Sentinel、Seata 等企业扩展。
- 用户要求长期计划完整包含主要、次要和扩展技术；统一按 P0 主线、P1 中线、P2 专项、P3 认知分层，每季度最多一个主专项，不同时学习全部技术。
- 技术全集入口为 `04-资源与评估/技术栈全景地图.md`，24 个月及后续路线为 `03-执行计划/长期学习路线.md`。
- 学习项目依次为：个人博客、协作任务平台、电商交易 Demo（仅模拟支付）、综合 SaaS 毕业项目。
- 正式内容分为 `01-阶段课程`、`02-项目实战`、`03-执行计划`、`04-资源与评估`；进度在 `03-执行计划/进度看板.md` 维护。
- Markdown 使用 Obsidian 相对内部链接；新增或移动文件后应检查链接有效性。
