# 全栈能力自检清单

> 评分标准：0 = 不了解；1 = 能复述；2 = 能在教程下实现；3 = 能独立实现并测试；4 = 能解释取舍、诊断故障并指导他人。
>
> “已学过”不算证据。求职前核心 P0 项应达到 3，关键项目相关项应能展示代码与验证。

## 1. 工程基础（P0）

- [ ] 使用终端、Git 分支、diff、合并与冲突处理完成工作。
- [ ] 能建立最小复现，使用断点、日志、网络面板和堆栈定位根因。
- [ ] 理解依赖、锁文件、环境变量、构建产物和秘密管理。
- [ ] 能编写他人可执行的 README 和验证命令。
- [ ] 能使用一种企业常用 AI 编程工具完成需求、计划、限定 diff、测试、独立复审和人工复盘，并控制秘密与修改范围。
- [ ] 能分析常见算法与数据结构的时间/空间复杂度。
- [ ] 理解进程、线程、内存、文件、网络和字符编码基础。

## 2. Web 与前端基础（P0）

- [ ] 编写语义化 HTML、原生表单和键盘可访问交互。
- [ ] 使用 Flexbox/Grid 和响应式策略实现复杂布局。
- [ ] 解释层叠、继承、盒模型、定位和层叠上下文。
- [ ] 解释 URL 到页面呈现、HTTP 方法、状态码和缓存。
- [ ] 解释 Cookie 属性、同源、CORS、CSRF 与 XSS 的关系。
- [ ] 使用开发者工具分析网络、渲染和可访问性问题。
- [ ] 能结合自动扫描与键盘、焦点、缩放等人工检查验证 WCAG 2.2 AA 相关风险，并说明未覆盖项。

## 3. JavaScript 与 TypeScript（P0）

- [ ] 理解作用域、闭包、原型、this、模块与可变性。
- [ ] 解释事件循环，并处理 Promise 错误、超时、取消和竞态。
- [ ] 区分网络失败、HTTP 非 2xx、解析失败和业务失败。
- [ ] 使用严格 TypeScript、泛型、收窄和判别联合建模。
- [ ] 使用 `unknown` 与运行时校验处理不可信外部数据。
- [ ] 编写可测试模块，避免以 any、断言和吞异常消除问题。

## 4. React 与前端架构（P0）

- [ ] 设计组件与状态边界，避免冗余 state 和 Effect 滥用。
- [ ] 处理路由、表单、分页、筛选和 URL 状态。
- [ ] 区分 UI 状态与服务端状态，处理缓存、失效和请求竞态。
- [ ] 实现加载、空、错误、权限、重复提交和离线反馈。
- [ ] 实现 Dialog 等组件的焦点、键盘和语义支持。
- [ ] 使用 Testing Library 和 E2E 验证用户行为。
- [ ] 基于测量优化包体、网络、渲染和长任务。

## 5. Node.js 与 API（P0）

- [ ] 解释事件循环、非阻塞 I/O 和 CPU 密集型任务风险。
- [ ] 实现模块化单体的路由、服务、数据访问分层。
- [ ] 设计 REST 资源、错误结构、分页、过滤和 OpenAPI。
- [ ] 对所有外部输入做运行时校验和大小/频率限制。
- [ ] 实现安全密码哈希、会话/Token 生命周期和服务端授权。
- [ ] 处理超时、取消、优雅退出、连接释放和依赖失败。
- [ ] 编写业务单元和真实 API 集成测试。

## 6. 数据库与缓存（P0）

- [ ] 设计 ER 模型，并使用主外键、唯一、非空和检查约束保护数据。
- [ ] 手写 Join、聚合、CTE、窗口函数和稳定分页。
- [ ] 使用参数化查询并分析执行计划、索引与 N+1。
- [ ] 解释事务、隔离、锁、死锁和乐观/悲观并发控制。
- [ ] 用数据库约束、事务与幂等键保证并发正确性。
- [ ] 设计可验证迁移、备份与恢复流程。
- [ ] 理解 ORM 生成的 SQL，能必要时使用受控原始 SQL。
- [ ] 实现 Cache Aside、TTL 与失效，并说明缓存故障和一致性。

## 7. 测试、安全与性能（P0/P1）

- [ ] 依据风险设计单元、集成和 E2E，而非只追求覆盖率。
- [ ] 覆盖正常、失败、边界、权限、重复和并发场景。
- [ ] 控制测试数据、时间、随机数与第三方依赖。
- [ ] 对认证、越权、XSS、注入、CSRF、上传和 SSRF 做针对性验证。
- [ ] 能将项目证据映射到 OWASP Top 10:2025 A01–A10，覆盖配置、供应链、日志告警和异常处理。
- [ ] 日志、错误和依赖扫描不泄露秘密或敏感信息。
- [ ] 能建立用户数据清单，并验证最小化、访问权限、保留/删除和第三方流向。
- [ ] 使用延迟、吞吐、错误率、饱和度建立性能基线。
- [ ] 设计超时、退避、重试预算、幂等、降级和故障注入实验。

## 8. 部署与运维（P0/P1）

- [ ] 使用 Linux 权限、进程、端口、磁盘和日志诊断问题。
- [ ] 编写多阶段、非 root、无秘密的容器镜像和 Compose。
- [ ] 配置 DNS、反向代理、TLS、健康检查和合理超时。
- [ ] 建立格式、Lint、类型、测试、构建和扫描组成的 CI。
- [ ] 实现可追溯发布、兼容迁移、回滚和备份恢复演练。
- [ ] 能在本地 Kubernetes 完成 Deployment/Service/Ingress、探针、配置、滚动发布/回滚和 Pod 故障诊断。
- [ ] 使用结构化日志、请求 ID、指标和 Trace 定位故障。
- [ ] 完成发现、止损、恢复、验证和复盘闭环。

## 9. 系统设计与协作（P1）

- [ ] 先澄清功能、非功能需求、规模和成本，再设计。
- [ ] 能获取或模拟需求证据并标明边界，把用户故事追踪到规则、测试和交付证据。
- [ ] 能处理一次需求变更，说明影响、优先级和被延期的范围。
- [ ] 能做容量估算、API/数据建模并识别单点和瓶颈。
- [ ] 理解缓存、负载均衡、队列、后台任务与最终一致性。
- [ ] 解释幂等生产者/消费者、重复消息、重试和死信。
- [ ] 能比较单体、模块化单体与微服务的收益和成本。
- [ ] 用 ADR 记录决策，用证据讨论方案而非堆术语。
- [ ] 能进行代码审查，区分阻断问题、建议与个人偏好，并留下修复和回归证据。

## 10. 求职与独立交付（P0）

- [ ] 至少两个可运行项目，其中一个是非教程综合项目。
- [ ] 能在 3 分钟内演示主流程，在 20 分钟内解释技术深挖。
- [ ] 简历中的架构、指标和职责均与证据一致。
- [ ] 能讲解真实 Bug、性能优化、安全修复和关键取舍。
- [ ] 不会的问题能说明边界和验证路径，不编造经验。
- [ ] 建立每周复习、项目维护和针对岗位差距补学的机制。

## 11. 中线 Java/Vue/MySQL 交付（P1）

- [ ] 使用 Java 集合、泛型、异常、并发和资源管理实现可测试业务逻辑。
- [ ] 能解释 JVM 内存、GC 基础并阅读至少一种真实诊断信息。
- [ ] 使用 Spring Boot、Validation、Spring Security 和统一错误实现 API。
- [ ] 使用 JUnit 5、AssertJ、Mockito、Testcontainers 覆盖单元与真实数据库边界。
- [ ] 比较 JPA/Hibernate 与 MyBatis，处理 N+1、事务、迁移和 SQL 控制。
- [ ] 比较 PostgreSQL 与 MySQL 的索引、锁、隔离和 SQL 方言。
- [ ] 使用 Vue 3、Router、Pinia 和组件测试实现完整用户路径。
- [ ] 能用真实代码和结果说明主线与中线的选择及迁移成本。
- [ ] 能交付含 Outbox、幂等消费、Nacos、Sentinel 和 Trace 的可靠事件模块，并演示重复、失败与恢复。
- [ ] 能比较本地事务、Outbox、Saga 与 Seata，不以分布式事务替代可简化的本地设计。

## 12. 长期专项能力（P2）

按所选方向检查，不要求每项都达到 3：

- [ ] TypeScript 深化：NestJS、Next.js/Nuxt、GraphQL/tRPC、Monorepo 或微前端。
- [ ] Python：FastAPI/Django、SQLAlchemy、pytest、后台任务、数据或 AI 应用。
- [ ] Go/.NET/其他后端：能完成服务、数据库、并发、测试、诊断和部署。
- [ ] 高级前端/跨端：设计系统、可视化、PWA/WASM、移动、桌面或实时媒体。
- [ ] 数据平台：文档/搜索/分析/时序/向量存储、消息、CDC 或数据质量。
- [ ] 云原生/SRE：Kubernetes、IaC、GitOps、OpenTelemetry、SLO 和故障演练。
- [ ] AI 应用：结构化输出、工具调用、RAG、权限、评估、成本和提示注入防御。
- [ ] 架构与交付：主导过迁移、遗留改造、开源贡献或复杂故障复盘。

## 13. 技术适应与选择（P2/P3）

- [ ] 能通过官方文档和最小实验学习陌生框架，不依赖特定课程。
- [ ] 能为新技术写清问题、核心模型、替代方案、成本和不适用场景。
- [ ] 能设计对照实验，而非凭热度或主观印象宣称技术更优。
- [ ] 能维护、升级和迁移旧项目，处理依赖、安全和兼容风险。
- [ ] 每季度只设一个主专项，并明确继续、保持认知或停止投入。
- [ ] [[技术栈全景地图|全景地图]] 中的 P3 项仅有认知时不标记为“掌握”。
