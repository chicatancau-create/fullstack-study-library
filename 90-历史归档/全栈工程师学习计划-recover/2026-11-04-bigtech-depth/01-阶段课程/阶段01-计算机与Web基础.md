# 阶段 01：计算机与 Web 基础

**建议周次：第 2–5 周｜优先级：P0｜目标：理解网页如何被请求、传输、解析和呈现。**

## 阶段目标

- 独立完成语义化、响应式、具备基础可访问性的静态网站。
- 能通过开发者工具解释一次 HTTP 请求和页面渲染过程。
- 建立后续学习后端、性能、安全和数据结构所需的基础。

## 学习清单

### HTML 与可访问性

- [ ] 文档结构、语义元素、表单、表格、媒体与元信息。
- [ ] 标签、属性、DOM 与 HTML 字符串的区别。
- [ ] 键盘操作、焦点、label、替代文本、对比度和标题层级。
- [ ] 不依赖 div 和 CSS 模拟所有原生交互。

### CSS 与页面实现

- [ ] 盒模型、文档流、选择器、层叠、继承和优先级。
- [ ] Flexbox、Grid、定位、溢出、层叠上下文。
- [ ] 相对单位、媒体查询、移动优先和响应式图片。
- [ ] 动画的 transform/opacity、减少动态效果偏好和基本性能边界。
- [ ] 能根据设计稿拆分布局，不逐像素堆绝对定位。

### 浏览器与网络

- [ ] URL、DNS、TCP/TLS 的作用，以及 HTTP 请求/响应结构。
- [ ] 常用方法、状态码、Header、Content-Type、缓存和条件请求。
- [ ] Cookie、SameSite、HttpOnly、Secure、Domain、Path。
- [ ] 同源策略、CORS 的触发条件和预检请求。
- [ ] HTML 解析、CSSOM、渲染树、布局、绘制、合成的大致过程。
- [ ] HTTP/1.1、HTTP/2、HTTPS 能解决什么，不能解决什么。

### 计算机基础（与项目并行）

- [ ] 进程、线程、内存、文件描述符和操作系统基本职责。
- [ ] 二进制、字符编码、UTF-8、时间与 UTC 的基本概念。
- [ ] 数组、链表、栈、队列、哈希表、集合、树和二叉搜索树。
- [ ] 大 O 表示法；能分析常见遍历、查找、排序的复杂度。
- [ ] 二分查找、双指针、递归；理解递归终止条件和调用栈。

## 最小实践

1. 不使用框架实现 3–5 页响应式网站，包含导航、列表、详情和表单。
2. 使用浏览器网络面板记录静态资源、缓存命中、失败请求和慢请求。
3. 仅用键盘完成页面主要操作，并修复焦点和标签问题。
4. 手写哈希表使用示例、队列、二分查找，并为边界输入写测试。
5. 抓取一次 CORS 失败证据，再解释是浏览器、服务端还是客户端配置问题。
6. 对核心页面运行 axe 或 Lighthouse 可访问性检查，再人工验证键盘顺序、焦点可见性、200% 缩放和减少动态效果；记录工具未覆盖的项目。

可访问性以 **WCAG 2.2 AA** 为参照。自动扫描只能发现部分问题，分数不能替代人工操作和真实用户反馈。

## 阶段验收

- [ ] 在常见手机与桌面宽度下无横向溢出、遮挡或不可点击区域。
- [ ] 核心页面自动扫描无未处理的 serious/critical 问题，人工检查有记录，未验证项明确写出。
- [ ] 能画出“输入 URL 到页面显示”的主要步骤，不确定处明确标注。
- [ ] 能解释 200、201、204、400、401、403、404、409、422、500 的使用差异。
- [ ] 能说明 Cookie 与本地存储的差异，以及 XSS 对它们的影响。
- [ ] 数据结构与复杂度练习不依赖框架，关键边界有验证。

## 常见误区

- 背状态码而不观察真实请求；把 401 与 403 混为一谈。
- 只会组件库，不会原生表单、布局与可访问性。
- 把 Lighthouse 分数当作完整可访问性证明，忽略键盘、焦点和缩放。
- 过早刷大量算法题；本阶段以常用结构、复杂度与代码能力为主。
